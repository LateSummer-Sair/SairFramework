# 网页抓取（工具 `web`：单动作工具，op 名就是 `web`）

权限上**有门槛**：抓取由技能管控表按 op **`web`** 判（`WebSkill` 里 `h.need("web")`）——
没给授权的身份（账本里 `Run["web", …]` 那行没写他）= **不可用**，拒绝文案带 `[权限阻断]` 标识，
要特例放行由主人在账本 `skillctl.json` 里补身份；她本人 `SYSTEM` 与主人不受表影响、恒全权
（好感度不决定任何权限）；与权限无关的 SSRF 闸门见下面「安全闸门」。

抓一个具体网址，把内容整理成模型能读的样子：

- 内容像 JSON（`{` / `[` 开头且能解析）→ 用 Gson 美化后返回；
- 否则按 HTML 处理：去掉 `script/style/注释`，块级标签转行，去标签、解实体，压掉多余空行；
- 想自己看原始 HTML（找结构、取属性）时传 `raw: true`。

## 参数
| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `url` | string | 是 | 完整网址；只写域名时会补 `http://` |
| `max` | integer | 否 | 最大字符数，默认 4000，上限 20000（≤0 或非数字按默认；超过上限夹到 20000） |
| `raw` | boolean | 否 | 默认 false；true 时不解析，直接返回原始内容（同样截断） |

## 返回
正文文本（第一行是 `GET <最终地址>（HTTP <状态>，<字符数> 字符，编码 <编码>）` —— 这个数**是解码后的字符数**，代码传的是 `Http.Res.body` 的 `length()`；占位符名 `{bytes}` 与 Java 绑定、别改）；超长时末尾附 `…（已截断，原始 N 字符）`。失败返回 `[web] 抓取失败：…`（DNS 失败、超时、HTTP 4xx/5xx 都会说清是哪种）。

## 文案在哪
**全部在 `prompt.md`**（本文件夹里）：拒绝内网 / 拒绝协议 / 重定向异常 / 抓取失败 / 空正文 / 结果头 / 截断尾巴。
缺键时技能明确回 `[web] prompt.md missing text: 键名` —— **没有兜底文案**，改文案只改 `prompt.md`（改完即生效）。

## 安全闸门（SSRF）
抓取走基板的 `Http.getGuarded`，判定在基板 `kit/NetGuard`（技能改不动）：

- **拒绝**环回（`127.0.0.0/8`、`::1`、`localhost`）、私网（`10/8`、`172.16/12`、`192.168/16`）、
  链路本地（`169.254/16`，含云元数据 `169.254.169.254`）、唯一本地 IPv6（`fc00::/7`）、
  运营商 NAT（`100.64/10`）、保留/组播段，以及云元数据域名（`metadata.google.internal` 等）；
- **IP 变形一起处理**：十进制 `2130706433`、十六进制 `0x7f000001`、八进制 `0177.0.0.1`、少段 `127.1`、
  末尾点 `localhost.`、IPv6 方括号 `[::1]`、IPv4 映射 `::ffff:127.0.0.1`；
- **域名先解析再判**（解析出的任一地址是内网就拒；解析失败按非内网放行，与原口径一致）；
- **重定向逐跳复检**：JDK 的自动跟随被关掉，`Location` 由基板自己解析，**每一跳在发起连接前**重新判定
  （否则 `http://外面/` 302 到 `http://169.254.169.254/` 就绕过了），最多 5 跳。

## 编码（非 UTF-8 网页不再乱码）
响应体统一按基板 `kit/Text` 的口径解码：**BOM → Content-Type charset → `<meta charset>` →
严格 UTF-8 → GBK → GB18030 → 强制 UTF-8 兜底**；实际用的编码写进结果头（`编码 GBK`）。
`Content-Encoding: gzip/deflate` 的响应会自动解压。

## 实现要点
- 超时 15 秒；跳转由基板逐跳处理（最多 5 跳）；UA 用浏览器标识，尽量少被挡。
- 只读：不落盘、不改任何数据。抓到的东西要留档，用 `note` 工具自己记。
- 响应体超过基板 `Http` 的 `DEF_MAX_BYTES`（8MB）会被**静默截断**（读到上限就停，不报错、结果头里也看不出来），
  被截断的大 JSON 常常解析不出来（`looksJson` 不过就按 HTML 去标签）——怀疑抓到的东西不完整时，先想到这一点。

## 使用建议
- 用户贴了 URL 就**必须**真的抓一次再回答，不要照着链接文字编内容。
- 搜索结果只有标题没有摘要时，挑一条最相关的链接抓正文。
- 页面是动态渲染（JS 加载）时正文可能是空的 —— 如实说明"抓到的正文是空的"，别硬凑。
- 抓到的长文要提炼，不要把 4000 字原文倒给用户。
