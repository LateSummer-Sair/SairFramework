# 出图（工具 `image`）

自己画图，然后**直接发到当前会话**。

## 六种 op

| op | 干什么 | 关键参数 |
|---|---|---|
| `card` | 文字卡片/海报：标题 + 正文 + 署名 + 圆角边框 | `title` `text` `sign` `theme` `w` `h` |
| `chart` | 数据图表：柱状 / 折线 / 饼图 | `kind` `data`（标签=数值，逗号分隔）`title` |
| `qr` | 二维码（可带说明文字） | `text` `caption` `size` |
| `pattern` | 程序化图案背景 | `kind`（gradient/stars/stripes/grid/noise/blobs）`color1` `color2` |
| `html` | HTML 片段或网址 → 截图（排版最自由） | `html` 或 `url` `w` `h` |
| `edit` | 加工已有图片 | `src` `action`（crop/scale/rotate/round/gray/wm） |

## 技术底子（为什么零安装）

| 部件 | 来源 |
|---|---|
| 画布/文字/形状/渐变 | JDK 自带 Java2D（BufferedImage + Graphics2D），中文走系统「微软雅黑」 |
| 二维码 | 框架 plugins/lib 里现成的 zxing |
| HTML 排版 | Edge 无头截图（每张一个临时 profile，不跟正在跑的 Edge 抢锁） |
| 图片加工 | Java2D（灰度逐像素、圆角走 clip、旋转走仿射） |

**没有接任何文生图模型** —— 那需要 API key，是另一条路。

## 能力边界（说清楚，别硬吹）

**能做**：文字海报/晚安卡、数据图表、二维码、图案背景、HTML 精排、裁剪缩放圆角灰度水印。

**做不了**：写实人像、动物、风景、任意物体 —— 这些本质要扩散模型。

## 纪律

- **一次一张**，别连发（每分钟默认上限 8 张，超了会被拒）；
- 画完就发，事实行里 sent=image 表示真的发出去了；控制台会话发不出去，只回路径；
- 这是「自己画的图」，不要假装是照片。
