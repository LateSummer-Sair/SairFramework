# 点名引用 · 文案与开关
# 本文件是本插件唯一的配置源：教学文案、清单模板、两个 CQ 模板都在这里。
# 格式：`键: 值` 一行一条；`#` 开头的行是注释；行内第一个冒号（半角 `:` 或全角 `：`）是分隔符。
# 读法：惰性缓存 + 按文件 mtime 失效 —— 每条消息不读盘，改完保存**下一条消息就生效**，
#       不需要 reload、不需要重启。改 .java 或 .md 的 front matter 才要 reload。
# Java 里只留「文件读不到 / Host 为 null 时的兜底默认值」：与下面各行的出厂值一一对应。

## 开关
# 关掉 = 教学段、清单段都不出现，标记也不换 CQ 码（等于这个技能没装）。
开关: true

## 教学（稳定段：逐字不变 ⇒ 走模型前缀缓存，成本几乎为零）
教学标题: 【点名与引用】@ 谁、引用哪条你自己定，技能只照你写的执行
教学1: @ 谁：写 <at qq="他的QQ"/>（QQ 见下条清单）；引号是必须写的形状，标签里除了 qq= 不要再加别的属性。
教学2: 引用哪条：写 <quote id="那条id"/>（id 见清单），引号同样必须写；号码必须是纯十进制数字 —— 别在标签里写 >、别在数字后面拖 / 或空格尾巴，那样的标记会被整段丢掉、引用就悄悄没发生。
教学3: 都不写 = 就发纯正文（默认，不必刻意补 @）。
教学4: 别人说过「别 @ 我」就别再 @ 他；只引用你真正在回的那条；QQ 与 id 只能抄清单，不许自己编。

## 清单（易变段：每轮现算，只对群生效）
# 它是"给你做决定用的原料"，不含任何判断：不告诉你该 @ 谁，也不告诉你该引用哪条。
清单标题: 【本群最近消息】（要 @ 谁、引用哪条，你自己定）
# 占位符（字面替换）：{id} 消息号 / {qq} 说话人 QQ / {name} 昵称 / {text} 说了什么 / {ago} 多少秒前
清单行: - id={id} qq={qq} {name}: {text}
清单尾: 上面按时间排，最后一条就是刚来的那条。
清单空: 【本群最近消息】暂时没有可引用的记录（那就什么都别加，只发正文）。

## 记账
# 清单条数：每个群在入站环里最多留几条（旧的挤掉）。
清单条数: 10

# 清理间隔秒：多久（秒）扫一次 `pick:` 前缀、把很久没动过的行删掉（避免库无限增长）。

## CQ 模板（她写了标记，就按这两个模板换）
# @模板：{qq} = 她写的 QQ。
at模板: [CQ:at,qq={qq}]

私聊不@: true

## 备注（不解析，只给人看）
# 这个插件不给模型任何工具（md 的 front matter 里没有 `tool:`）。它做三件事：
#   1) on_message 记账：把本群最近几条入站（谁/几号/说什么/什么时候）记进 kv；
#   2) 两段上下文：教学段（怎么写）+ 清单段（有哪些 id 与 QQ 可抄）；
#   3) 出站收尾：把她写的 <at qq=".."/> / <quote id=".."/> 就地换成 [CQ:at,qq=..] / [CQ:reply,id=..]。
# 它**不判断**：不看谁是主人、不看回复多长、不看时间差、不记"上一轮是谁"、不做任何兜底补 @。
# 她没写标记 ⇒ 一个字节都不改。要不要 @、@ 谁、引用哪条，全是她的决定。
#
# 为什么两个标记一定安全：`at` / `quote` / `reply` 都在基板 qq\MarkerTags 的白名单里，
# 而剥除发生在出站 stage **之后** ⇒ 插件读得到、用户看不到；就算插件没跑，基板也会剥掉，
# 绝不会有一条裸标签发给用户。
#
# 号码校验：标记里的号必须是十进制且 > 0，否则标记直接丢掉（宁可没有前缀，也不发畸形 CQ 码）；
# 她若自己写了同号的 CQ 码，标记只被丢掉、不重复加（避免两个 at 挂在一条消息上）。
