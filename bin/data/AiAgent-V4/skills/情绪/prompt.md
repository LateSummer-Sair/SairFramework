# 按人按群隔离：一行 = 一个「人在一个场合」——
#   私聊 scope=private、scope_id=<QQ>；群聊 scope=group、scope_id=<群号>:<QQ>。
#   所以 A 群被骂出来的怒气不会出现在 B 群、也不会出现在私聊里。
#   V3 的怒气是**全局一个值**，它自己被这件事咬过（见 EmotionStateManager.noteUnfriendlyGroup 的注释：

# 恋爱三道门（V3 原样）：表白要「当前不是恋人、不是背叛者、且亲疏 >= 恋爱门槛(800)」，

#   注入段里不许有随机数（同一状态同一轮两次装配必须逐字节一致），随机只会让前缀缓存与复现都变差。

# 时钟容差秒：on_message 优先用事件时间（事件里的 time 是上游机器的钟），
