# 情绪 · 配置与文案
#
# 本文件是「情绪」插件唯一的配置源：阈值、词表、正则、档位文案、注入模板全在这里。
# 保存即生效（Java 侧惰性缓存 + 按 mtime 失效，下一条消息/下一轮装配就换用新值），不需要重启、不需要重编译。
# 格式：`键: 值` 一行一条（行内第一个半角或全角冒号是分隔符，值里可以再带冒号）；`#` 开头是注释。
# 值里的 `\n` 会被还原成换行（要写多行模板时用）。
# Java 里只留**标量**的兜底默认值（预算、衰减分钟与幅度、上下限、每日亲疏、衰减批量、平静标签、无名对象），
#   兜底值与这里的出厂值一一对应；**效果规则与档位这两张表没有 Java 兜底** ——
#   本文件读不出来时它们为空：那一刻不累积、注入行里没有心情/态度/语气/关系（模板与数字仍在）。
#
# 三张表（各自的解析规则不一样，改之前先看一眼）：
#   ① 配置        `键: 值`                      —— 开关、阈值、上限、模板
#   ② 效果规则    `<族>-<名>: <词表> => <效果>`  —— 族 = 情绪 / 触发 / 正则
#   ③ 档位        `<族>-<组>-<档名>: <条件> | <文案>` —— 族 = 心情 / 表情 / 态度 / 关系 / 语气
#
# 口径来源：V3 `sair\aiagent\onebot\EmotionStateManager.java`（0~100 的怒气/伤心状态机、
# 好感度分级态度、恋爱/背叛者/前任）与 `data\prompts\modules\context\emotion*.md`（语气与关系文案）。
# 数字与词表都照 V3 抄，一处发明的地方都写在「备注」里。

#   ① 网格 = 墙上时钟的**固定格**：slot = floor(now / 20 分钟)。不是"从上次情绪开始算的滑动窗口"。
#   ② 翻页（slot 变了）只做三件事：状态回 calm、计数/指纹/次账本清零、trigger=grid；since 同时更新为
#      翻页判定时刻。所以"翻页"这一刻 **since 一定会变**（since 不变 ⇒ 没有翻页，见 ④）。
#   ③ 翻页是**懒结算**，三个触发点任一到就结算：下一条入站消息 / 基板 tick 的 on_timer / peek(now>0) 的只读视图。

#      这是刻意的（"同一状态两次 build 逐字节一致"靠它），**不是"20 分钟没重置"**。
