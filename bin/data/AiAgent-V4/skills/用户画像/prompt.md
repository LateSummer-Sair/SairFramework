# 用户画像 · 文案与阈值
# 本文件是本插件唯一的配置源：五维名字、别名、好感档与态度模板、条数、预算全在这里。
# 格式：`键: 值` 一行一条；`#` 开头的行是注释（`## 配置` 这种分节标题也是注释）；
#       行内第一个冒号（半角 `:` 或全角 `：`）是分隔符，值里可以再带冒号。
# 读法：惰性缓存 + 按文件 mtime 失效 —— 每轮不读盘，改完保存下一轮生效，不需要重启。
# Java 里只留「文件读不到 / host() 为 null 时的兜底默认值」，兜底值与下面前几行一一对应。
#
# ⚠ 这一段是**稳定段**（stable()=true）：同输入必须逐字节不变，否则模型服务的前缀缓存每轮失效。
#   所以：模板里**没有**时间戳类占位符（{ts}/{age} 之类故意不提供），也别把本轮正文塞进来。
#   改动本文件会让"同输入"变成"输入变了"，这是允许的（配置本来就不是输入的一部分），
#   但改完最好连着一起看：改一次 = 下一次装配的前缀全变，属正常代价。

## 备注（不解析，只给人看）
# 开关：false = 本段这一轮不出现（不读库、不读好感）。
# 维度：五维印象的名字与**渲染顺序**（V3 的 impression-distill.md 五维：emotionStability /
#   interests / speakingStyle / honesty / imageHabit，另一项 impressionLevel=印象好坏不在这里）。
#   维度名字要与印象记忆正文里的标签一致，否则那一条会掉进「补充」。
# 维度别名：`别名=正式名` 逗号分隔。用来收下 V3 的老标签（情绪状态/兴趣爱好/虚实态度/图片习惯）
#   与英文键（emotionStability…）。别名只是**解析期的翻译**，渲染出来的一律是「维度」里的正式名。
# 态度键：印象正文里用这几个标签写的行会被当成「态度」（第一命中者胜）。
#   第三批的「情绪」插件将来也可以往 memory 写一条 `态度: …`，本插件不用改就能读到。
# 印象来源：只认 source 命中这些词的记忆行（逗号分隔多个；相等或包含都算）。
# 印象标签：source 没命中时，tags 里含这个词的行也算印象（兜底口径，逗号就一个词）。
# 印象取样条数：每次从 memory 取多少行来筛（scope=user + scope_id=本人，按 ts 从新到旧）。
#   这只是上限，不影响渲染条数；取多了不显著增加开销，取少了会漏掉老印象。
# 印象条数：最多用多少条「印象记忆」来拼这一段（凑够就不再看更老的行）。
# 预算：本段的字符上限，也是 maxChars() 的返回值（默认 600）。
#   注意：maxChars() 拿不到 Host，所以它用的是「上一次读到的预算」，首次调用前是 600。
# 主人显示好感：false = 主人自己的画像里不显示好感行（主人不需要好感档；这里读的是 favor 表，没有对主人做特判）。
# 显示零好感：false = 好感为 0（新人）时不打好感行，免得每个人头上都挂一行「好感: 0」。
# 无名对象：调用者没带昵称时 {name} 的替代值。

# 占位符（{键} 字面替换；**没有**时间类占位符，见上面的稳定段说明）：
#   标题 / 对象行 / 行模板 / 原文模板 / 好感档模板 / 态度行模板：
#     {name} 调用者昵称（空则用「无名对象」）、{qq} 调用者的 QQ
#   行模板：{label} 标签（五维名或补充标签）、{value} 值
#   原文模板：{text} 整行原文（{value} 同值）
#   好感档模板：{level} 好感档名（基板 favor 视图给的名字）、{value} 好感数值
#   态度行模板：{value} 态度文本
# 标题 / 对象行：留空 = 不打这一行。

# 数据从哪来（只读，绝不写）：
#   ① 印象：memory 库 scope=user, scope_id=<这个人 QQ> 且 source=印象蒸馏（或 tags 含「印象标签」）的行；
#      每行正文按「标签: 值」解析：标签命中「维度」或别名 → 五维；命中「态度键」→ 态度；
#      其它带冒号的 → 补充（按遇到顺序）；**没有冒号的整行** → 原文补充。行按新→老遍历，同一个键先到者胜。
#   ② 好感档：基板只读视图 h.favor()（本插件改不了好感度）。
#   ③ 态度：见上（没有就整行不打）。
#   「印象蒸馏」是谁写的：第三批的「群印象」插件（或记忆技能手工记的行）。
#   本插件只读 memory 库，不建库、不写库、不自己开库、不写 SQL。
