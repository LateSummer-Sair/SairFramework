# 批量处理（工具 `batch`；写前逐目标判 `W`，读源图判 `R`）

两个**危险** op：正则批量改名、图片批量转格式。这个技能的设计原则是"宁可少做，不可做错"：

1. **只动数据目录以内** —— 相对路径按 `h.conf().root()` 解析，一律先 `getCanonicalFile()` 再比前缀：
   `../`、绝对路径、符号链接逃逸 **一律明确拒绝**（回一句拒绝文案，不是"忽略"）。
   遍历时**跳过符号链接**，每个条目再过一次 canonical 校验。
2. **动作前先报数量** —— 先扫出候选清单（数量、预览前若干条），候选超过「文件数上限」直接拒绝，
   让你先缩小范围，而不是一把梭。目标已存在的文件**跳过不覆盖**。
3. **默认试运行** —— `dry_run` 缺省取 `prompt.md` 的「默认试运行」（true）：
   不显式给 `dry_run:false`，一个字节都不落盘。
4. **非主人能不能改，取决于目标自己那一档的位** —— 两个 op 动的是基板数据目录以内的文件，**逐目标判位**
   （不再拿数据根的写位把整批否掉）：`rename` 在写前循环里判「源文件 `W` + 目标 `W`」
   （`BatchSkill` 的写前循环 `needPath(目标,'W')`），`convert` 判「源图 `R` + 目标图 `W`」
   （`BatchSkill` 的读源图判定 `needPath(from,'R')`）；判不过只让**那一个目标**失败（`fail++`），
   并把 **ACL 拒绝原文**收进结果，不再整批一律拒。数据根里 `files/` **以外**的部分是 **B 类**，
   `ALLUSER` 无位（∅）⇒ **非主人改不了**；而 `files/` 树属 **C 类、无专有位** ⇒ 非主人只读（`R`）⇒
   **非主人改不动 `files/` 里的文件**（示例里 `files/pics` 就是这一类）。
   主人恒全权，她自己（`SYSTEM`）B 类默认 `R|W`。（工具属 **T 类（只判入口）**、**工具可见性按 `T:X` 筛**（`ALLUSER` 默认 `T=无` ⇒ 他的工具清单为空）：
   能不能做看五类的按类默认分配 **＋ 账本例外条目**（`Entry` 命中即用它的位，唯一放宽通道 = `perm` 的授权 op），
   能不能答应对方看事实块 `caller.bits` —— `ALLUSER` 默认 `T=无` ⇒ 非主人一把工具都用不了，要特例放行。）

## `rename` —— 正则批量改名

| 参数 | 说明 |
|---|---|
| `dir` | 必填，数据目录内的目录 |
| `pattern` | 必填，匹配**主名**（不含扩展名）的正则 |
| `replacement` | 必填，替换串（支持 `$1` 分组） |
| `ext` | 可选，只处理这些后缀；不填则按「图片后缀」白名单（受「只收图片」开关控制：关掉后该目录所有普通文件都进候选，含 `.json`/`.bat`，危险） |
| `recursive` | 可选，递归子目录（默认 false） |
| `dry_run` | 可选，默认 true |

- **扩展名保留**：`IMG_12.png` + `^IMG_(\d+)$` → `photo_$1` ⇒ `photo_12.png`；
- 正则不合法、替换串非法、目标名与原名相同 → 分别如实说明 / 跳过；
- 目标已存在 → 记为"冲突"并跳过（不覆盖别人的文件）。

## `convert` —— 图片批量转格式

| 参数 | 说明 |
|---|---|
| `dir` | 必填 |
| `to` | 必填，`png` / `jpg` / `jpeg` / `gif` / `bmp`（`jpeg` 归一成 `jpg` 再写；既要在本机 ImageIO 能写、又要在「允许格式」白名单里） |
| `from` | 可选，只处理这些后缀；不填按「图片后缀」白名单（同样受「只收图片」开关控制：关掉后该目录所有普通文件都进候选，含 `.json`/`.bat`，危险） |
| `out` | 可选，输出目录（不填原地输出） |
| `recursive` / `dry_run` | 同上 |

- 已经是目标格式的文件跳过；目标文件已存在且「覆盖已存在: false」时跳过；
- 读不出来的（不是图片 / 编码不支持）记为跳过，不报异常；
- 写 `jpg` / `bmp` 前会按「背景色」把透明区压平（否则透明会变黑）。
- **WebP 不在白名单里**：标准 ImageIO 没有 WebP 读写器，写了也是失败 —— 要支持得另加库。

## 返回样式

```
将要改名 3 个文件（试运行，没有改动磁盘）：
1. files/pics/IMG_1.png → files/pics/photo_1.png
2. files/pics/IMG_2.png → files/pics/photo_2.png
3. files/pics/IMG_3.png → files/pics/photo_3.png
```

## 正确的用法顺序
1. 先 `dry_run`（默认）看一眼数量与清单；
2. 数量对得上、名字也对，再带 `dry_run:false` 重发同一条；
3. 只处理一层时别开 `recursive`；处理完可以再用「文件」技能 `list` 复核。
