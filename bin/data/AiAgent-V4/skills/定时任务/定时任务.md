# 定时任务（工具 `cron`，任务存 C 类 `kv`，按会话归属隔离，钩子 `on_timer`）

一张 cron 任务表，外挂一个到点判定钩子。**技能自己不跑模型**：到点只做一件事 ——
`h.spawnAs(创建者, 任务, 工具白名单, true, …, 目标会话)`，把活交给主 Agent，立刻返回。

## 权限（C 类运行时数据 + 会话归属硬判）
| 层 | 口径 |
|---|---|
| 资源判定 | 建/删任务 = 写 `kv`（`h.needDb("kv", 'W')`）、列任务 = 读 `kv`（`'R'`）。C 类对非主人只有 `R`（`RWX` 只有 `SYSTEM` 有）⇒ 写一律被位拦下、**非主人建不了也删不了**（要特例放行），建任务本身不是提权 ⇒ **add/remove 不判主人**（位判定照旧生效） |
| `add` | 写位过得去的人才能建（非主人被位拦下，要特例放行），登记的行带上**创建者的归属**（会话 + QQ + 群） |
| `list`（只读 op） | 按**归属**过滤：主人看全部，其他人只看自己会话建的 |
| `remove` | **逐行过归属**（非主人写位先被拦下）：写位过了之后删别人的行只回 `[cron] 定时任务 #N 不是你建的，删不了。`；`all=true` 清掉的是自己能看到的那些 |
| 到点执行 | 按**创建者**的身份判定（能力继承）：主人建的照旧全权，普通人建的按他自己的位判；取不到归属回落到 `SYSTEM`，**绝不回落 MASTER** |
| 到点投哪 | 投回**建任务时记下的那个会话**（任务行的 `session`：`group:<群号>` / `qq:<QQ>` / `console`）—— 换会话、换群之后提醒仍回到原处；老数据行没有这个键、或会话认不出来 → 回落**控制台**（不报错、不丢任务） |

> 换句话说：**任务是谁建的，到点就按谁的位跑**。别人看不见也用不了 `cron` 这个工具（`ALLUSER` 默认 `T=无`），也就看不到、删不掉别人会话来路的行。
> 两类拒绝文案**不要混**：**归属硬判**（本技能自己判的）回的是 `prompt.md` 的「只能删自己的」，形如
> `[cron] 定时任务 #N 不是你建的，删不了。` —— **不带** `[权限阻断]` 标识；
> **资源判定**才是基板 `h.need*` 的原文 `缺 X 位 —— [权限阻断] …`（`[权限阻断] ` 就是 `Acl.DENY_PREFIX` 的值，前缀不在首位）；
> 工具可见性按 `T:X` 筛（`ALLUSER` 默认 `T=无` ⇒ 他的工具清单为空；工具本身属 T 类、只判入口），能不能答应对方看事实块 `caller.bits`（非主人一把工具都用不了，要特例放行）。

## 表达式：`分 时 日 月 周`
| 写法 | 含义 |
|---|---|
| `*` | 任意 |
| `*/n` | 从该段最小值起每 n 个（如 `*/5` 每 5 分钟） |
| `a` | 单个值（如 `9`） |
| `a-b` | 区间（如 `1-5`） |
| `a-b/n` | 区间内每 n 个 |
| `a,b,c` | 逗号列表，任意命中即可 |
| `a/n` | 从 a 到该段最大值的每 n 个 |

- 周：`0`=周日，`1`=周一 … `6`=周六（`7` 也当周日）。
- **日与周都写了具体值**（都不是 `*` 开头）时按 cron 惯例取**或**：`0 0 1 * 1` = 每月 1 号**或**每周一。
- 例：`*/5 * * * *`（每 5 分钟）｜`0 9 * * 1-5`（工作日 9:00）｜`30 8 1 * *`（每月 1 号 8:30）。

## 三个 op

### `add`
参数 `expr`（必填）、`task`（必填）、`tools`（可选）。建任务 = 写 `kv`（`h.needDb("kv", 'W')`），
登记的行带上创建者的归属。
返回 `已建定时任务 #3：0 9 * * 1-5 → 下次 2026-01-05 09:00。到点会让主 Agent 去做：…`

### `list`
列出**自己能看到的**任务：主人看全部，其他人只看自己会话建的（与基板闹钟 `owner` 语义一致）。
非主人只能看、建不了（建任务 = 写 `kv`，C 类对非主人只有 `R` ⇒ 写一律被位拦下，要特例放行）；一条都没建过才回 `还没有定时任务`；别人的行他看不到。
每条给出：id、表达式、下次触发、上次触发、任务正文、工具白名单、归属。

### `remove`
参数 `id`（或 `all=true`）。写 `kv`（`h.needDb("kv", 'W')`）之后**逐行过归属**（硬判）：
非主人删不了任何行（写位先被拦下，要特例放行）；写位过了之后删别人的行只回 `[cron] 定时任务 #N 不是你建的，删不了。`

## 到点怎么触发（`on_timer`）
```java
long minute = System.currentTimeMillis() / 60000L;      // 按分钟取整
if (row.last_fired == minute) continue;                  // 本分钟已触发 → 不重复触发
if (!expr.matches(now)) continue;                        // 分 时 日 月 周 逐个判定
row.last_fired = minute; store.kvSet(kvKey, json(row));  // 先记，再派发
h.spawnAs(创建者主体, 派发任务文案, tools, true, …, 目标会话);  // 按创建者的身份跑；落点 = 建任务时的会话
```
- **派发主体 = 任务的创建者**（能力继承）：钩子自己的主体是 `SYSTEM`（她自己的自主行为），
  但派子 Agent 时用 `h.spawnAs` 把主体换成创建者 —— 主人建的照旧全权，普通人建的按他自己的位判；
  取不到归属（老数据行没有 `owner`）回落到 `SYSTEM`，**绝不回落 MASTER**；
- **落点 = 建任务时记下的那个会话**：派发时把任务行的 `session` 一并交给 `h.spawnAs`（第 8 位参数，
  真签名 `spawnAs(Caller, task, tools, async, brief, model, reply, session)`），由基板解析成真落点 ——
  **换会话、换群之后提醒仍回到原处**；老数据行没有 `session`、或会话键认不出来 → 回落**控制台**；
- **防重复触发**：`last_fired` 记的是"分钟"，所以同一个 tick 周期里连来几拍、或者派发被基板挡下，
  都不会在同一分钟内重复触发；
- **派发被挡不丢账**：`h.spawnAs` 回 `rejected`（子 Agent 达上限）时日志里能看到，任务仍算作这一分钟已触发。

## 存储（kv）
| 键 | 内容 |
|---|---|
| `kv.cron:seq` | 自增 id |
| `kv.cron:t:<id>` | 任务行 JSON：`{id, expr, task, tools, ts, last_fired, owner:{session,qq,group,master,name}, session}` —— 顶层 `session` 是**到点投递的目标会话**（见上表「到点投哪」；老行没有这个键 → 回落控制台） |

## 阈值与文案在哪
全部在同目录 `prompt.md`（`最多任务`、`列表上限`、`下次触发最多向前找分钟`、以及全部对外文本）。
工具与钩子**每次**都重读它，改完即时生效；缺键时会明确报 `prompt.md missing …`，不用隐藏默认值。

## 与基板 `alarm` 的分工
`alarm` 是"几点叫我"的一次性/固定间隔唤醒（基板自己带表）；`cron` 是"按日历规则周期性做事"的技能。
两个都存在，互不干扰 —— 要复杂的日历规则用本技能，要"20 分钟后提醒我"用 `alarm` 更省事。
