表达式非法: [cron] 表达式「{expr}」不合法：{reason}
原因_段数: 要 5 段（分 时 日 月 周），现在是 {n} 段
原因_空段: 有空的段「{part}」
原因_步长: 段「{part}」的步长不是正整数
原因_范围: {field} 段「{part}」超出范围（{lo}-{hi}）
原因_数字: {field} 段「{part}」不是数字
任务太多: [cron] 定时任务已达上限（{limit} 条），先 remove 掉不用的再建。
已建: 已建定时任务 #{id}：{expr} → 下次 {next}。到点让主 Agent 去做：{task}
列表空: 还没有定时任务。用 op=add 建一个（expr 如 "0 9 * * 1-5"）。
列表头: 定时任务 {count} 条（范围：{scope}）
列表项: #{id} {expr} → 下次 {next}{last}\n    {task}\n    工具：{tools}｜归属：{owner}
列表还有: …（还有 {rest} 条未列出）
范围_全部: 全部（主人视角）
全部工具: 主 Agent 全部工具
没有这个任务: 没有 id={id} 的定时任务。
只能删自己的: [cron] 定时任务 #{id} 不是你建的，删不了。

已清空: 已清空你自己的 {count} 条定时任务。
没有下次: 算不出下次触发时间
到点: [定时任务] 到点 #{id}（{expr}）：{task}
派发任务: 定时任务（{expr}）到点了，请你去做这件事：{task}。做完把**要发给用户的那句话**直接写出来（基板会替你发到建任务时的那个会话；不要报任务号/工具名/内部过程，不要调用发送工具）；这件事不需要对外说话就只回 <silent>。
时间格式: yyyy-MM-dd HH:mm
最后触发: （上次 {time}）

## 说明
# cron 语义：分 时 日 月 周（5 段）。支持 *、*/n、a、a-b、a-b/n、逗号列表；周 0=周日（7 也当周日）。
#   例：*/5 * * * *（每 5 分钟）｜0 9 * * 1-5（工作日 9:00）｜30 8 1 * *（每月 1 号 8:30）
# 日与周都写了具体值（都不是 * 开头）时按 cron 惯例取「或」：任一命中就触发。
# 到点判定：记 kv 的 last_fired（按分钟），同一分钟只触发一次；触发时用 h.spawnAs(创建者, 任务, 工具, true, …, 目标会话)
#   唤起主 Agent（不占钩子线程）。落点 = 建任务时记的会话（换会话/换群仍回原处）；老行/认不出 → 控制台。
# 权限：任务存 C 类 kv，按 R/W 位判（非主人默认只有 R，写要特例放行）；add/remove 不判主人。
# 归属硬判（不看位）：list 按 owner 过滤（主人全看），remove 只删自己的。
# 到点按创建者身份判定（能力继承）；取不到归属回落 SYSTEM，绝不回落 MASTER。
