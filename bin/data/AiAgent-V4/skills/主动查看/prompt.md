## 文案（面向模型/用户；日志前缀 [主动查看] 由代码加）
查看说明: 群 {group} 最近有 {count} 条新消息，最新一条是 {name}：{text}。要不要接一句由你自己定 —— 想接就**只输出要发出去的那句话本身**（不要写说明、不要报内部过程、不要调用发送工具，基板会替你发）；不想说就只回 <silent>，一个字都不会发出去。别复述原话、别说“我注意到”。
首次游标: 群 {group} 第一次查看：先把游标记到 {cursor}，这一轮不插话
未启用: 未启用（启用: {enabled}）或没配 监控群，本轮不动作
静默中: 静默时段（{window}）内不动作
冷却中: 群 {group} 还在冷却（还剩 {left} 分钟）
间隔未到: 群 {group} 距上次查看还不到 {gap} 分钟
没有新消息: 群 {group} 没有新消息
不达标: 群 {group} 新消息 {count} 条，不到 {need} 条，不值得开口（游标推进到 {cursor}）
关键词未命中: 群 {group} 有新消息但没命中关键词，不开口（游标推进到 {cursor}）
决定开口: 群 {group} 新消息 {count} 条（最新 {name}：{text}）→ 已派给主 Agent（{status}）
静默时段非法: 静默时段「{window}」看不懂（要 HH:mm-HH:mm），按不动作处理
缺配置: 缺少配置「{key}」，本轮不动作
全部工具: 主 Agent 全部工具
时间格式: yyyy-MM-dd HH:mm

## 说明
# 监控群：群号，逗号分隔；留空 = 不监控任何群（技能完全不动作）。
# 间隔分钟：同一个群两次"查看"之间的最小间隔（0 = 不节流）。没到点连 grouplog 都不查。
# 最少新消息：距上次查看之后至少有这么多条新消息才考虑开口（>=1）。
# 静默时段：HH:mm-HH:mm（支持跨零点，如 23:00-08:00）；空 = 不静默。静默期内完全不动作，也不推进游标。
# 冷却分钟：开口之后这段时间内不再开口（0 = 不冷却）。冷却期与静默期都不推进游标 —— 消息攒着，等能说话时一起看。
# 关键词：非空时只统计命中关键词的新消息（命中不到就不开口）；空 = 不看关键词。
# 工具白名单：派给子 Agent 的工具，逗号分隔；空=全部（子Agent继承触发者身份，按bits判）。
# 判定顺序：启用/监控群 → 静默 → 冷却 → 间隔 → 游标(首次只建游标) → 新消息数/关键词 → 开口。
# 开口 = h.spawn(查看说明, 工具白名单, true)，把"要不要说、说什么"交给主 Agent —— 本技能从不直接发消息。
