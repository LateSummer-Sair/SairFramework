# 主动查看（`on_timer` 钩子，**不注册工具**，钩子按 `SYSTEM`（她自己的自主行为）跑）

"隔一会儿看一眼某个群，值不值得说句话。"判定与文案全在 `prompt.md`，数据全来自基板六库的 `grouplog`。
**从不直接发消息**：判定"值得"时也只 `h.spawn(...)`，把"要不要说、说什么"交给主 Agent。

## 判定顺序（一个群一次）
1. `启用` 必须为 true，且 `监控群` 里点名了群 —— 出厂是 `启用: false` + `监控群` 空，**什么都不做**；
2. 不在 `静默时段` 内（`HH:mm-HH:mm`，支持跨零点；写错了按"不动作"处理，不猜）；
3. 不在 `冷却分钟` 内（上次开口之后）；
4. 距上次查看 ≥ `间隔分钟`；
5. 读游标：`check:cursor:<群>`。**第一次看到这个群只建游标、绝不插话**（否则一上线就对着历史消息开口）；
6. 统计游标之后的新消息（`h.store().list("grouplog", {group_id, _gte:{id:cursor+1}}, ...)`）：
   **一次最多取 200 条**（`ProactiveCheck` 里的常量 `MAX_FETCH`，按 id 升序取最早的 200 条）——
   超过 200 条时只按这 200 条统计，而游标仍会推到该群当前最大 id（代码里推游标那几支用的都是 `maxId`），
   也就是**第 200 条之后那一段不会再补看**（`最少新消息` 默认 5，正常群聊一分钟到不了 200 条；
   真的刷屏时要留意这一档）；
   - `关键词` 非空时只算命中关键词的那些，一条都没命中 → 不开口；
   - 新消息数 < `最少新消息` → 不开口；
7. 够格 → `h.spawn(查看说明, 工具白名单, true)`，并记 `check:spoke` / `check:cursor` / `check:last`。

## 游标语义（为什么这样设计）
- **只有"看完了但没什么可说"才推进游标**：静默、冷却、间隔未到这三种情况**不推进**，
  消息攒着，等能说话的时候一起看 —— 不会因为静默一小时就把这一小时的消息丢掉；
- 新消息数不够 / 关键词没命中，说明"这一段没什么值得说的"，游标推进（看过了就算了）。

## 配置（全在 `prompt.md`）
| 键 | 含义 |
|---|---|
| `启用` | 不为 true → 完全不动作（出厂 false） |
| `监控群` | 群号，逗号分隔；空 = 不监控（出厂空） |
| `间隔分钟` | 同一个群两次查看的最小间隔（0 = 不节流）；没到点连 `grouplog` 都不查 |
| `最少新消息` | 游标之后至少这么多条新消息才考虑开口（≥1） |
| `静默时段` | `HH:mm-HH:mm`，支持跨零点；空 = 不静默 |
| `冷却分钟` | 开口之后这段时间内不再开口（0 = 不冷却） |
| `关键词` | 非空时只统计命中关键词的新消息（**正文或昵称**命中即算，大小写不敏感）；空 = 不看关键词 |
| `工具白名单` | 派给子 Agent 的工具，逗号分隔；空 = 主 Agent 全部。**工具可见性按 `T:X` 筛**（`ALLUSER` 默认 `T=无` ⇒ 他的工具清单为空；工具本身属 T 类、只判入口），子 Agent 继承触发者身份，按 `caller.bits` 判该不该做（非主人一把工具都用不了，要特例放行） |
| `查看说明` | 派发任务的模板，占位符 `{group} {count} {name} {qq} {text} {time}` |

## 落库 / 观测
| 键 | 内容 |
|---|---|
| `kv.check:cursor:<群>` | 已看过的最后一条 `grouplog` id（游标） |
| `kv.check:sweep:<群>` | 上次查看时间（`间隔分钟` 用） |
| `kv.check:spoke:<群>` | 上次开口时间（`冷却分钟` 用） |
| `kv.check:last:<群>` | 最近一次开口记录：`{ts, group, count, cursor, last, spawn}` |
| 控制台 | `[主动查看] …`（未启用 / 静默中 / 冷却中 / 间隔未到 / 首次游标 / 不达标 / 关键词未命中 / 决定开口） |

## 为什么默认保守
主动说话是**打扰**：群里没人问、消息也没攒够时开口，比不说话更糟。所以这里三层闸门
（静默时段、冷却、最少新消息）默认都开着，出厂还额外把整个技能关掉（`启用: false`）——
要用就得在 `prompt.md` 里明确点名群号并打开开关。改 `prompt.md` 即时生效（钩子每次心跳重读它）。

**被动优先是默认姿态**：有人提及（被 @ / 私聊）才回、回复慢点没关系，不值得为了"显得在线"去看群开口。
没配 `监控群` 时连 `grouplog` 都不查、游标都不建（出厂就是这一档）。
