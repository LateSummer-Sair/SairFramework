## 提取提示词
你在为「印象蒸馏」提炼某个人的长期印象。

素材是他最近的群聊发言与私聊记录（时间顺序，越靠后越新）。
请只提炼"关于这个人本身"的、以后还用得上的东西：性格倾向、说话习惯、长期偏好、稳定事实（身份、职业、常聊的话题）、明确表达过的喜恶。
不要提炼：一次性的闲聊、与这个人无关的公共信息、当时的临时情绪、别人说的话。

输出要求（严格遵守）：
1. 只输出一个 JSON 数组，不要输出解释、不要包 Markdown 代码块；
2. 数组每个元素形如 {"label":"兴趣","content":"...","importance":0-10,"tags":["..."]}；
3. label 只能从这几个里逐字挑一个：{labels} —— 挑最贴切的那个；都不合适就写空串 ""；
4. content 用一句陈述句（20-60 字），主语是这个人，不要照抄原话；
5. importance 是"这条印象以后有多重要"：9-10=长期身份/核心偏好，6-8=稳定习惯/明显倾向，0-5=不确定或一次性的，宁缺毋滥；
6. tags 是 1-3 个短标签（例如：性格、偏好、身份、说话习惯）；
7. 没有值得记的就输出 []，不要为了凑数编造。

对象 QQ：{qq}
对象称呼：{name}
素材条数：{count}

素材：
{msgs}

## 备注（不解析）
# 启用：不为 true 就整个技能不动作（工具 op 也会说"没有启用"）。
# 间隔小时：两次"真正跑起来的轮次"之间的最小间隔，支持小数（0 = 不节流，只建议手工调试时用）。
#   **这个间隔记在基板 kv 表里（distill:impression:last），进程重启不会重置**：
#   重启后第一次 tick 只要距上次成功蒸馏已经超过「间隔小时」，就正常补一轮（见 kv distill:impression:done）。
# 失败重试分钟：上一轮以模型失败/解析失败结束时用的短退避（失败时不占用长时间隔，但也不至于每 20 秒重打）。
# 每轮人数：on_timer / run 一轮最多处理几个人（按「挑人候选」池轮转着挑，不是每次都挑当下最活跃的那几个）。
# 挑人候选：候选池大小 —— grouplog 最近发言去重后的前 N 个人。轮转游标落在 kv distill:impression:cursor，
#   每轮从游标处往后取「每轮人数」个没在「间隔小时」内蒸过的人，然后游标前进；
#   这样重启不倒退、每轮往前走，群里人多也不会一直重复蒸同几个话痨。
# 每人取样条数：grouplog 取最近多少条 + dialog 取最近多少条（两边各取这么多，再按时间排序）。
# 最少消息条数：样本不足这么多条就跳过这个人（不浪费模型调用）。
# 最低重要度：模型给的 importance 低于这个值就直接丢弃，不写库。
# 目标库：写进哪个库，默认 memory；必须是含 scope/scope_id/importance 列的库（别的值会退回 memory）。
# 按人还是按群：**按人**。行永远是 scope=user + scope_id=QQ（跨群同一身份），取样会把他在所有群与私聊里
#   的发言并到一起蒸馏；这一轮取样覆盖到的群号写进 extra.groups（来源场合，记忆技能回想时会标出来）。
#   不做"按群各存一份"：那样换个群就认不出是同一个人了。
# 对话角色：dialog 里收哪些 role 的发言（逗号分隔；留空或写 all = 不过滤）。默认只收 user，即"这个人自己说的话"。
# 每条最大字数：单条素材截断长度，防止样本把上下文撑爆。
# 查重最短长度：归一化后"包含即算重复"所需的比较长度下限，防止短句误判（比较前会先剥掉「标签: 」前缀）。
# 印象标签：写进 tags 的第一个标签。**本技能定位自己的行不用它** —— 定位走 `source` + `scope` + `scope_id`
#   （见 Java 里的 `J.obj("scope", …, "_like", J.obj("source", …))`）；这个标签是给按标签找行的插件用的
#   （例如「用户画像」）。
# 维度标签：模型给的 label 只有逐字命中这个清单才会写成正文前缀，正文形状是「标签: 值」——
#   **这是「用户画像」插件的解析约定**（它按「一行一条 标签: 值」把 memory 行的 content 拆成
#   五维 情绪稳定/兴趣/说话风格/诚实度/发图习惯 与 态度；没有冒号的整行只会当"原文补充"渲染）。
#   所以这个清单要与 用户画像/prompt.md 的「维度」+「态度键」**保持包含关系**：用户画像是五项维度
#   （情绪稳定/兴趣/说话风格/诚实度/发图习惯）+ 三个态度键（态度/关系/印象）= 8 项；
#   本技能默认只列前五维 + 态度（6 项），`关系`/`印象` 不主动产出（模型给了也会按"清单外"写成纯句子）。
#   要么把这两项补进本清单，要么知悉这处不对称 —— 别以为两边"逐字相等"。
#   模型没给合法标签时写纯句子（不会丢）。
# 样本行群聊 / 样本行对话：给模型看的素材行格式，占位符 {time} {group} {qq} {name} {role} {text}；
#   提取提示词里的占位符：{qq} {name} {count} {msgs} {source} {labels}。
