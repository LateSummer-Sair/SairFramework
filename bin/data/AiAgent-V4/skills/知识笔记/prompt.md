# 知识笔记（工具 note）· 阈值与文案
# 本文件是本技能唯一的阈值与文案来源：技能每次调用都重读它 —— 改这里即时生效，不需要改 Java。
# 格式：一行一条「键: 值」；# 开头的行是注释；空行忽略。
# 值里的 \n 会还原成换行；{xxx} 是占位符。
# 本技能**多数键没有隐藏默认值**：删掉后用到它的路径会明确报「缺键」。
# 两个例外（缺省时静默降级、不报缺键）：`正文长度上限`（缺省 = 不限）、`标题前缀`（缺省 = 不剥前缀）。

## 配置

#   0.85 = V3 PersistenceManager.findNearDuplicateNoteId 的笔记阈值（标题即身份）。
相似阈值: 0.85
# 相似取样条数：查近似时从 note 库取最近多少条标题来比（只有标题参与，代价很小）。
相似取样条数: 200

指纹最短项数: 4

# 正文长度上限：超过就明确拒绝（0 = 不限）。

## 说明
# 查重两道：① 标题完全相同 → 覆盖更新（"已有同名笔记"）；
#   ② 标题近似（Jaccard ≥ 相似阈值）→ 也更新（"已有近似笔记"），并在 kv note:dup_hit 上累加命中次数。
#   第二道是 V3 util/TextFingerprint 的等价物：同主题的"略有差异标题"不该反复堆成新条目。
#   判定只用标题、不用正文（正文往往是模板化的搜索结果堆，用它会误并"同主题不同问题"）。
# search：h.store().search("note", query, limit)（FTS5 trigram，无命中回退 LIKE）。
# 归属硬判（不是权限位）：note 是共享知识库、行里没有归属列 ⇒ 非主人写/改/删一律拒，读口仍开放（NoteSkill.noteWriteGuard）。
