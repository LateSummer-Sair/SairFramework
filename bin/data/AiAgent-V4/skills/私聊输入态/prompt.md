## 配置
开关: true

## 文案
# 本插件不产出任何"说给用户听的话"（它不提供工具、不改正文、不追加消息），所以这一节是空的。
# 它的产物就是"正在输入"这个状态本身：回合开始打开、回合结束关掉。

## 备注（不解析，只给人看）
# 开关：true = 私聊回合开始调一次 Host.typing(true)、回合结束调一次 Host.typing(false)；
#   false = 两个钩子直接 return，一轮都不调（含回合结束那一半），等于没装。
#   注意它是**两半一起**的：不存在"开了不关"或"关了还开"的中间态。
# 为什么只有一个键：本插件的动作只有一个（基板的具名能力 Host.typing），
#   什么时候开、什么时候关由基板的回合时序决定，插件没有别的可调项。
# 群聊不受本文件影响：群聊在读到本文件之前就 return 了（NapCat 群聊没有这个动作）。
# 改坏了（写错值、写错键名）：按兜底值 true 处理，不会让插件变成"关不掉"的状态。
