# 联网搜索（工具 `search`：单动作工具，op = `search`，按技能管控表判）

抓 `https://www.bing.com/search?q=...` 的结果页，解析出标题 / 链接 / 摘要返回；出网走基板的带闸门入口 `Http.getGuarded`（环回 / 私网 / 链路本地 / 云元数据一律拒绝，每一跳重定向复检；判定本体在基板 `kit/NetGuard`，技能改不动）——与同族「网页抓取」同口径。适合"上下文里没有、需要外部事实"的问题（新闻、版本号、人物、行情、梗的来源）。

权限上**有门槛**：搜索是一次出网执行（op = `search`，`SearchSkill` 里判 `h.need("search")`），
技能管控表里没给这个身份授权（**空** = 没写这条，或写了没给身份 / 命中 **Ban**）⇒ **非主人用不了这把工具**。
要放开只能由主人在表（数据根 `skillctl.json`）里写一行，例如 `Run["search","ALLUSER"]`；
她本人 `SYSTEM` 与主人恒全权（好感度不再决定任何权限）。

## 参数
| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `query` | string | 是 | 搜索关键词 |
| `count` | integer | 否 | 返回条数，默认 5，上限 10 |

## 返回
```
必应搜索 <关键词>：<n> 条
1. 标题
   https://真实链接
   摘要文字
2. …
```
`[search] 搜索失败：…` 表示没网 / 必应不可达 / 被反爬；`没有解析出结果` 表示页面结构变了或返回了验证页；
`[search] 这个地址指向内网（主机 · 类别），按安全口径不搜：地址` 表示**被 SSRF 闸门拦下** —— 回的是内网拒绝说明，不是「搜索失败」，也不是网络问题。

## 文案在哪
本技能**暂无 `prompt.md`**：面向模型的文案（`[search]` 开头的搜索失败 / 没有解析出结果 / 内网拒绝）目前**硬编码在
`SearchSkill.java` 里** —— 改文案要改 Java，改这份 md 不生效。（收拢进 `prompt.md` 属另一笔改动。）

## 实现要点
- 解析优先用 jsoup（classpath 上有就反射调用），没有则回退内置正则解析 —— 技能是运行期由基板编译的，不能假定宿主 classpath 一定有 jsoup。
- 必应的跳转链接（`bing.com/ck/a?...u=a1<base64>`）会被还原成真实 URL 再返回。
- 超时 15 秒；任何异常都转成一句可读说明，绝不抛给模型。

## 使用建议
- **多对象拆分搜索**：一次只搜一个对象，多个对象拆成多次调用（可以并发派给子 Agent），最后合并分析。
- 搜到的东西要落成笔记就先 `note` 查重再写，别重复存。
- 只有链接没有摘要时，用 `web` 工具抓那一条具体网址看正文，别靠标题猜内容。
- 拿不到就说拿不到，不要用记忆里的旧信息冒充搜索结果。
