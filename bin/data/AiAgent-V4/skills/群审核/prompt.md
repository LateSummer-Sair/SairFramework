异常: [群审核] 执行异常：{error}

# 说明
# 启用：on / true / 1 / yes / 是 才算开；关掉 = 这个群（或全部群）不审核。
# 违规词：逗号分隔，命中任意一个即算违规（英文不区分大小写）；**出厂留空 = 默认不审**
#   （主人裁定：不设默认词表，要审就自己配；裸 http:// https:// 不再默认命中）。
# 禁言秒数：< 60 会被抬到 60。
# 跳过群：这些群完全不审核，多个用逗号分隔；留空 = 所有群都审核（只在本文件里配，按群配置用 on: false）。
# 豁免角色：group 角色名（owner=群主 / admin=管理员 / member=普通成员）。
# 豁免QQ：这些 QQ 号无论发什么都不处理（白名单），多个用逗号分隔。
# 警告文案：{name} 昵称、{qq} QQ号、{group} 群号、{word} 命中的词、{mute} 秒数。
# 规则说明：给模型/人看的群规说明，不参与判定，会显示在 op=config 的输出里。
# 主人（master）无论写什么都不会被审核。
#
# 按群覆盖（kv 键 modcfg:<群号>，JSON）：
#   {"v":2,"on":true,"words":["词1","词2"],"mute":600,"roles":["owner","admin"],
#    "users":[10001],"warn":"…","note":"…","updated":1699999999999,"by":10001}
#   只写要给这个群换的键；其余键继续用上面的全局默认。on=false = 这个群不审。
