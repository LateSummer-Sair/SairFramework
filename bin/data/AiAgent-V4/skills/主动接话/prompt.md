# 说明
# 启用：不为 true → 整个技能一次都不动作（出厂 false，默认保守；被动优先是默认姿态）。
# 关键词：逗号分隔；没命中就完全不考虑接话（默认保守，宁可不接）。
# 间隔秒：两次接话之间的最小间隔；每日上限：每天最多接几次（0 = 不限）。
#   ⚠ 这两项有 Java 兜底：缺键或值读不出来时按 300 / 5 走（其余项缺了就是不生效）。
# 只在这些群：群号白名单，逗号分隔；留空 = 所有群都适用。
# 接话说明：占位符 {name} 昵称、{qq}、{group} 群号、{text} 原话、{word} 命中的关键词。
# 本技能只往上下文注入说明，从不直接发消息；但它会投 `_reply=true` 一票 ——
