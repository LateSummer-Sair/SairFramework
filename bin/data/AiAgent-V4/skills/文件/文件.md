# 文件（工具 `file`；读判 `R`、写判 `W` —— 路径不被技能限定，能碰什么由 ACL 判）

一个工具管住"文件"：**读、看目录、找、下载、写**。技能**不限定**路径落在哪儿 —— 相对路径按基板数据根
（`conf.root()`，生产环境就是 `data/AiAgent-V4/`）解析，绝对路径原样采用，**能碰什么由 ACL 决定**：
工具不自己设一道比 ACL 更低的上限（主人裁定的口径：工具调用从最低权限开始、不行再逐步升级，
MASTER 到 MASTER、SYSTEM 到 SYSTEM、ALLUSER 的上限由例外清单决定）。于是数据根以外的 **A 类**资源
（例如 `D:\Share\MP3音乐文件\x.mp3`）也进得来：主人读它不必改用 `exec`（那等于把"读文件"升级成
最高权限的操作），账本给 A 类写的例外条目（`A["User123","D:/share","R"]`）也才真有工具用得上。

权限只看**资源类别**（路径落在哪一类，就按那一类的默认分配 + 例外清单判）：
**B 类**（数据根里 `files/` 以外的部分，含 `skills/**`）：`read` / `list` / `find` 读它判 `R`、
`download` 落盘与 `write` 写它判 `W`（`ALLUSER` 在 B 类一位都没有（∅）⇒ **非主人写不进 B 类**，
这是按类默认分配本身的结论，不是额外加的一道"仅主人"判定）；
**`files\` 树**（`<数据根>\files\**`）**属 C 类、没有专有位**（旧 `Acl.DEF_FILES` 已删，位一律服从 C；`Acl` 里对 `Res.isFilesTree()` 的那一支只用来让路径式范围命中它）：非主人 `R`（**写／执行一律被位拦下**）—— 所以她本人与主人照常，**非主人只读、写不进 `files/`**
（这是主人定的既定后果，不是缺陷）；
**A 类**（数据根以外的本机文件）：非主人**默认一位都不给**（`Acl.DEF_A`＝∅），要开只能靠**例外清单**
（`A["User123","D:/share","R"]`、`A["ALLUSER","","R"]` 这类条目 —— 清单就是上限）；
主人**恒全权**（A/B/C/E 都可以），她自己（`SYSTEM`）走自己的默认档（A:`R` B:`RW` C:`RWX`；SYSTEM 的 E = RWX（`Acl.SYS_E = Bits.ALL`））。
工具属 T 类（只判入口；六库/内存态仍是 C 类）、**工具可见性按 `T:X` 筛**（`ALLUSER` 默认 `T=无` ⇒ 他的工具清单为空）；能不能答应对方看事实块
`caller.bits` 的五列（非主人一把工具都用不了，要特例放行）。**被 ACL 拒时回执是账本原文**（形如 `缺 R 位 —— [权限阻断] …`，点明缺哪一位），
技能不另造一句 —— 调用方要靠这句话判断要不要升级到更重的工具。

**例外：不是所有 B 类路径都读得到** —— 第二层受保护资源的「按扩展名档」（`Acl.protectedExtRes` /
`Acl.PROTECTED_EXTS`）：B 类路径里以 `.json` / `.ini` / `.conf` / `.properties` / `.yml` / `.yaml` / `.toml` /
`.bat` / `.cmd` / `.ir` / `.xml` / `.env` / `.key` / `.pem` / `.p12` 结尾的**受限配置文件与脚本，非主人一律读不到**（大小写不敏感、精确 `endsWith`：
`export.jsonl` **不**匹配 `.json`，`.jsonl` 导出文件不在这一档）；她本人（`SYSTEM`）与主人照常，
**这一档例外条目也开不了**。所以上面"读得到"要按这条收着说：读数据根内**任意**文件并不是非主人的能力。
**这条只对 B 类路径生效**：`files/` 那块归 C 类，里面的 `.json` 等**不在**这一档（非主人照样读得到）。

## 五个 op

### `read` —— 读文本（只读）
| 参数 | 说明 |
|---|---|
| `path` | 必填；相对路径按数据根解析，**也可直接写绝对路径**（数据根以外也认，能不能碰由 ACL 判，见下） |
| `offset` | 起始行（1 起），默认 1 |
| `limit` | 最多返回行数，默认取 `prompt.md` 的 `默认读取行数`，上限 `最多返回行数` |

- 超过 `最大读取字节` 直接拒绝（先确认再读，别把上下文撑爆）；
- 内容含 NUL 字节判定为二进制，不支持阅读；
- **编码自动探测**（基板 `kit/Text`）：BOM → 严格 UTF-8 → GBK → GB18030 → 强制 UTF-8 兜底。
  GBK/ANSI 的 txt 不再整篇乱码；非 UTF-8 时控制台会打一行 `[文件] 按 GBK 解码：路径`。
  `find` 的内容匹配走同一口径（GBK 文件里的中文同样能被搜到）；
- 返回带行号：`3| 这一行的内容`，头部写明"共 N 行，显示 a-b"，被截断时末尾提示还有多少行。

### `list` —— 列目录（只读）
默认列数据目录本身：`[D] 子目录/`、`[F] 文件名  大小 字节  修改时间`，最多 `最多列出行数` 项。

### `find` —— 递归找（只读）
- 文件名包含关键词，或文件内容包含关键词（单文件 ≤ `最大扫描字节` 才搜内容）；
- 深度 `扫描深度`、最多扫 `最多扫描文件` 个文件、最多返回 `最多命中` 条；
- 内容命中的给出首次命中的行号与片段。

### `download` —— 下载到 `files/`
- 只接受 **http/https**（`file:`、`ftp:` 之类一律拒绝）；
- **走基板带闸门的下载入口 `Http.download`**：环回（`127.0.0.0/8`、`::1`、`localhost`）、私网
  （`10/8`、`172.16/12`、`192.168/16`）、链路本地与云元数据（`169.254.169.254`）、唯一本地 IPv6
  （`fc00::/7`）一律拒绝，**并且每一跳重定向都重新判定**（302 跳到内网同样被拦）；
  IP 变形（十进制 `2130706433`、十六进制 `0x7f000001`、八进制 `0177.0.0.1`、`127.1`、`[::1]`）一并处理；
  判定本体在 `kit/NetGuard`，技能改不动；被拒时用 `prompt.md` 的「下载拒绝内网」文案；
- 落点固定是 `conf.filesDir()`（数据目录下的 `files/`）：`path` 相对 `files/`，绝对路径也必须落在 `files/` 内，
  **越界直接拒绝**；`path` 留空则用 URL 里的文件名，取不到就用 `prompt.md` 的 `默认下载名`；
- 超过 `下载上限字节` 会被删掉并如实报告；
- 落盘前先过工具运行时的 `X` 位（`FileSkill` 的 download 分支判 `Res.tool("file.download")`，工具属 T 类、只判入口，
  `ALLUSER` 默认 `T=无` ⇒ 非主人一把工具都用不了，要特例放行），再判落点的写位（同一分支里的 `needPath(dst, 'W')`）—— 落点固定在 `files/`，
  而 `files\` 树属 C、无专有位 ⇒ 非主人只读（R）⇒ **非主人写不进 `files/`**；
- 返回 `已下载 <相对路径>（N 字节）← <url>`；没网/超时返回 `[file] 下载失败：…`，
  跳转链本身没走通（3xx 但没有 Location / 超过 5 跳）返回 `[file] 下载的跳转没走通（…）`，**都不抛异常**。

### `write` —— 写文件（**B 类写不进；`files/` 也写不进（属 C、无专有位 ⇒ 非主人只读）；数据根外的 A 类看例外清单**）
- 执行前判这个路径的写位（`FileSkill` 的 write 分支 `h.needPath(f, 'W')`）：B 类路径 = `W`，
  `ALLUSER` 在 B 类一位都没有（∅）⇒ 非主人**写不进 B 类**；**`files\` 树属 C、无专有位 ⇒ 非主人只读（R），也写不进**；
  数据根以外的 A 类非主人默认一位都没有（主人恒全权）；**不过就把 ACL 的拒绝原文原样返回**
  （技能侧形态＝`缺 W 位 —— [权限阻断] 需要 <资源> 的 W 位`，位名标签来自 `Host` 的 `needTag`）——
  调用方靠这句话判断要不要升级，技能不另造拒绝文案；
- **不再有"必须落在数据目录以内"这道自设边界**：能不能写全看 ACL；正文超过 `写入上限字节` 拒绝；
- **写前报字节数**：先把"将要写多少字节、原文件多大"写进控制台日志，再落盘；
- 返回 `已写入 <相对路径>（N 字节，M 行；原文件 K 字节）`。

## 路径怎么解析 / 结构性防护（关键实现）
```java
File root = h.conf().root().getCanonicalFile();     // 只是"相对路径相对于谁"，不是允许范围
File f = new File(p).isAbsolute() ? new File(p) : new File(root, p);
f.getCanonicalFile();                               // ① `..` 与符号链接：规范化（结构性，不是权限）
real(f);                                            // ② 目录联接/junction：toRealPath 解出真实位置
h.needPath(f, 'R' / 'W');                           // 能不能碰 —— 唯一权威；被拒就用它的原文回话
```
**没有"必须在数据根以内"这一步**：绝对路径原样采用，只有相对路径按 `root` 解析 —— 挡人的是账本，不是技能。
① 与 ② 仍然都做，是为了让 ACL 判**真身**：Windows 上 `getCanonicalPath()` **不解析目录联接（junction）**，
只做 ① 会让 `files/联接名/secret.txt` 看着像 `files/` 里的 C 类、实际指到数据根外面；`toRealPath()` 会把
最深一层已存在的祖先解成真实路径，所以不存在的新文件（write / download 的落点）也一起被管住 ——
别名（软链 / junction）换不来资源类别，这两道**防穿越**逻辑照旧在。
唯一的"必须在某处以内"是 `download` 的**落点**：`resolveIn()` 保留 ① + ② 两道前缀校验，因为那个 op 的语义
就是"下到 `files/` 里"，越界返回 `[file] 拒绝访问：下载只能落在数据目录的 files/ 里面：<path>`。

## 失败与拒绝
一律返回一句说明，不抛异常（文案全在 `prompt.md`，可以直接改）：
- `[file] 路径不合法（系统不接受这种写法，无法解析）：<path>`（输入不合法，不是权限拒绝）
- `[file] 文件不存在：<relative>` / `[file] 路径不存在：<relative>`
- `[file] 拒绝访问：下载只能落在数据目录的 files/ 里面：<path>`（只有 `download` 的落点会走这句）
- `[file] 文件太大（N 字节，上限 L）…` / `[file] 看起来是二进制文件…`
- `[file] 下载失败：<url>（<原因>）`
- `[file] 这个下载地址指向内网（<主机> · <类别>），按安全口径拒绝：<url>`（SSRF 闸门）
- `[file] 下载的跳转没走通（<原因>），最后停在：<url>`

被 ACL 拦下的那几句**不在 `prompt.md` 里**：它们由账本判定生成（`Acl` 的判定与 `Acl.source`），统一带 `[权限阻断]` 标识。
形态只有一种 —— `缺 X 位 —— [权限阻断] …`：**位名标签不在首位**（标签来自 `Host` 的 `needTag`：`缺 W 位 —— `），
接在它后面的是 `Acl.DENY_PREFIX` 那句账本原文。**权限面没装配**那一支（`auth == null`，只在早期装配/桩宿主里出现）
用的同样是 `Acl.DENY_PREFIX`，后面跟的是「权限面没有装配（auth == null），按拒绝处理：…」——
`Auth.DENY_PREFIX`（`[auth] 权限阻断：`）**只留给识别面兼容，不再出现在任何产出文案里**。

## 使用建议
- 用户说"读一下某个文件"时，先 `list` 看清目录，再 `read` 具体文件，不要瞎猜路径。
- 找东西优先 `find`（一次过滤掉大量文件），别一个个 `list` 翻。
- **主人要读数据根以外的文件（A 类）就直接 `read`／`find`**，不必绕道 `exec` —— 起进程是最高权限的一步，
  用它来"读个文件"等于把权限直接拉满；`path` 可以直接写 `D:\Share\...\x.mp3` 这样的绝对路径。
- 普通人/群要碰根外资源，得账本里给他开**例外条目**（例如 `A["User123","D:/share","R"]`）——
  清单就是上限；没开时回执会点明缺哪一位（`缺 R 位 —— [权限阻断] …`）。
- 要存网上的东西用 `download`，它会替你放进 `files/` 并告诉你路径与大小 —— 别自己去拼磁盘路径。
- `write` 非主人写不进 **B 类路径**（B 类非主人一位都没有），也写不进 **`files\` 树**（属 C、无专有位 ⇒ 非主人只读（R））；会被拒的是 B 类、`files\` 树与数据根外的 A 类（没开例外条目时）。非主人的拒绝说明带 `[权限阻断]`，这是设计，不是故障。
- 所有阈值与文案都在同目录 `prompt.md`，改完即时生效（技能每次调用都重读）。
