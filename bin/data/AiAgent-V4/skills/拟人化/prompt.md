# 拟人化 · 文案与阈值
# 本文件是本插件唯一的配置源：三条清洗规则（去头套话 / 去尾套话 / 压连续空行）全在这里。
# 格式：`键: 值` 一行一条；`#` 开头的行是注释（`## 配置` 这种分节标题也是注释）；
#       行内第一个冒号（半角 `:` 或全角 `：`）是分隔符。
#       ⚠ 正则里的冒号不要紧（分隔符只认**第一个**冒号），`[，。:：\s]*` 这样写没问题。
# 值是**正则原文**：`\s` 就写 `\s`（一个反斜杠），不要写成 `\\s`。
#        Java 侧走 String.replaceAll，等价于 V3 的写法。
# 读法：惰性缓存 + 按文件 mtime 失效 —— 每条消息不读盘，改完保存下一条生效，不需要重启。
# Java 里只留「文件读不到 / m.host() 为 null 时的兜底默认值」，兜底值与下面这三行逐字相同。

## 配置
开关: true
去头套话正则: (?i)^(作为\s*AI|作为人工智能|根据我的理解|希望以上信息对你有帮助)[，。:：\s]*
去尾套话正则: (?i)(希望以上信息对你有帮助|如果还有问题可以继续问我|有其他问题随时问我)[。！!\s]*$
最大连续空行: 2

## 备注（不解析，只给人看）
# 开关：false = 本插件这一条不改（等于没装）。
# 去头套话正则：只匹配**开头**（^ 锚定）；命中就整段删掉，包括后面跟着的逗号/句号/冒号/空白。
#   出厂值 = V3 原样（QQAgentBridge.java:242）：
#     (?i)^(作为\s*AI|作为人工智能|根据我的理解|希望以上信息对你有帮助)[，。:：\s]*
# 去尾套话正则：只匹配**结尾**（$ 锚定）；出厂值 = V3 原样（QQAgentBridge.java:243）：
#     (?i)(希望以上信息对你有帮助|如果还有问题可以继续问我|有其他问题随时问我)[。！!\s]*$
# 最大连续空行：连续的 "\n" 最多留几个。2 = V3 的 `\n{3,}` → `\n\n`（把 3 个以上连续换行压成 2 个）。
#   写成 1 就是"不留空行"；小于 1 会被当成 1。
# 套话正则（可多行，一行一条，默认没有）：**额外**的清洗规则，逐条做全文替换（不锚定首尾）。
#   要加就在下面加行，例如：
#   套话正则: (?i)作为一个?AI(语言)?模型
#   套话正则: (?i)抱歉[，,]我(无法|不能)
#   注意它是**全文**替换，写宽了会把正常正文也删掉（这就是它默认一条都没有的原因）。

# 与 V3 的关系（QQAgentBridge.java:239-247 postProcessReplyText）：
#   String t = text.trim();
#   t = t.replaceAll(去头套话正则, "");
#   t = t.replaceAll(去尾套话正则, "");
#   t = t.replaceAll("\\n{3,}", "\n\n").trim();     ← 最大连续空行 = 2
#   // 不再硬截断超长回复：分段发送负责完整拆条，确保「有多少输出多少」
# 本插件**不硬截断**、**不改写语气**、不做"把问句改成陈述句"这类事 —— 超出长度归分段管。
# 逐条生效：位置在分段之后、发送之前，所以三段的回复是三条各自洗（与 V3 同口径）。
# 洗成空串 = 这一条不发（基板口径：清洗完什么都不剩就等于没有这条）。
