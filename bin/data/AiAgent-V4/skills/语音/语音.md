# 语音（工具 `speak`）

把文字变成声音。底层用 **edge-tts**（微软 Edge 的在线朗读接口）：
**免费、不需要下载模型、不吃显存/显存**，一句 3 秒左右出 mp3。

## 两个 op

| op | 干什么 |
|---|---|
| `speak` | 文字 → mp3 → **在 QQ 会话里直接发出去**（语音消息）；控制台里只回路径 |
| `voices` | 列出可用中文音色（女/男/方言） |

## 男女声怎么选（四层，从高到低）

1. **`voice` 参数** —— 直接指定音色 ID，最硬；
2. **`gender` 参数** —— 女／男；
3. **她自己提示词里写的性别** —— 从 `data/prompts/identity.md` 渲染后的系统提示里找关键词：
   女生/女性/女孩/少女/妹子/姑娘/女声/妹妹/小姐姐（女），男生/男性/男孩/少年/男声/哥哥/小哥（男）；
   单独一个「她」「他」权重很低，只在没有明确词时才起作用；
4. **默认女声** —— 提示词没提性别时。

> 设计意图：让她**按自己的人设说话**。人设是女声就用女声，人设是男声就换男声，不用每次交代。

## 音色（中文）

| 性别 | 音色 ID | 特点 |
|---|---|---|
| 女 | `zh-CN-XiaoxiaoNeural` | 温暖自然，默认女声 |
| 女 | `zh-CN-XiaoyiNeural` | 活泼，适合撒娇/卡通 |
| 男 | `zh-CN-YunxiNeural` | 阳光生动，默认男声 |
| 男 | `zh-CN-YunyangNeural` | 新闻播音，稳重 |
| 男 | `zh-CN-YunjianNeural` | 有激情，适合解说 |
| 女 | `zh-CN-liaoning-XiaobeiNeural` / `zh-CN-shaanxi-XiaoniNeural` | 东北话／陕西话 |

## 配置（本技能自己的 `prompt.md`）

| 键 | 作用 | 默认 |
|---|---|---|
| `女声:` | 女声用的音色 ID | `zh-CN-XiaoxiaoNeural` |
| `男声:` | 男声用的音色 ID | `zh-CN-YunxiNeural` |
| `性别:` | 强制覆盖自动判断（女/男） | 空 = 自动 |
| `python:` | 跑 edge-tts 的 python（要装好 edge-tts） | `python` |
| `每分钟上限:` | 每分钟最多合成几次 | 10 |

## 纪律

- **单次最多 300 字**（超了拒，让她分段说）；
- **每分钟有预算**（防止被诱导疯狂发语音刷屏）；
- 合成失败如实说，**不假装发出去**；
- 语音消息走 `Host.sayMedia(..., "record", …)`，只能发给**当前会话**（不能发给别处）—— 这条是基板强制的。

## ⚠️ 语音是拓展能力，不是默认行为

**平时聊天一律用文本。** 只有触发者**明确要求**语音时才调本工具：

| 对方这么说 | 该不该用语音 |
|---|---|
| 「发条语音」「用语音说」「念出来听听」 | ✅ 用 |
| 「你好」「今天天气怎么样」「帮我查一下…」 | ❌ **不用，文本回** |
| 「你声音好听吗」这种半开玩笑 | ❌ 先文本答，除非他要求发 |

## 「语气提示词」到底能做到什么程度（重要）

**edge-tts 不支持自由文本语气**（写「温柔地说」「用撒娇的语气」它不认）。
它只暴露三个旋钮，所以「语气」在本技能里是**预设组合**：

| 语气 | 语速 | 音量 | 音调 | 听感 |
|---|---|---|---|---|
| 温柔 | -12% | -25% | +2Hz | 慢、轻、略偏少女（**甘雨默认**） |
| 平缓 | -18% | -15% | -2Hz | 更慢、更稳、偏低沉 |
| 欢快 | +8% | 0% | +6Hz | 快、亮、活泼 |
| 严肃 | -4% | 0% | -6Hz | 沉稳、像播报 |
| 耳语 | -15% | -45% | 0Hz | 很轻、贴近耳边 |

> 想要**真正的情绪/风格**（比如「带着哭腔」「压着笑」），那是 Azure Speech 的
> `mstts:express-as` 能力，需要**付费 Azure 订阅 key**。要上那条路我可以另开一个 op 接。

## ⚠️ 一次只发一条（真机踩过的坑）

**调一次 = 发一条语音 = 这一轮的回复。** 不要为了「换个声音再试一次」「再确认一下性别」而重复调用。

- 同一句话 **20 秒内重复调用会被拒**（返回「这条刚刚已经发过了」），不会真的再发一条；
- **性别不要手动换**：它按她自己提示词的性别走（判不出就女声）。`gender` 只在该由主人**明确要求换声线**时才传；
- 事实行里的 `gender=` / `voice=` 只是**回执**，不是判断「发没发出去」的依据 —— 写了 `ok=1 已发出` 就是发出去了。

> 为什么强调：之前 `speak` 没被基板当成「说话类工具」，框架会再跑一个收尾轮；
> 她于是以为语音没发成功、在文字里说「下一轮再补」，用户就收到「文字先说、语音下轮才到」。
> 现在基板已把 `speak` 算进说话类工具（语音即回复），这个坑已封。
