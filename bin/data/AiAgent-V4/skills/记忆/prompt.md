## 备注（不解析）
# 默认作用域：remember 不给 scope 时记到哪一层（user = 自己）。
# 作用域口径（记住时怎么选 scope，模型看到的是 记忆.md 的 airun.description）：
#   关于"这个人"的事 → user（他的 QQ）：性格、偏好、称呼、身份、他说过的话、他私下告诉你的事。
#     人本来就是同一个人，换个群也该认得出、接得上。
#   只在"这个群"成立的事 → group（群号）：群规、群内约定、群里的梗、需要在本群语境才成立的话。
#     跟着群走，不跟着人跨群跑。
#   全体都适用的通用结论 → global（非主人写 global 一律拒）。
#   拿不准就记 user（宁可跨群记得，也别把人记丢）；确实只在群里成立才用 group。
# 关于这个人（跨群）：recall 不给 scope 时分三节返回 —— ①【关于这个人】(scope=user, scope_id=当前说话的人)
#   ②【本群】(scope=group, 当前群) ③【全体】(scope=global)；每节最多「列表条数」条。
#   这一层是结构性行为、没有开关：人跨群是同一身份，关掉它就等于退回"记不住人"的老行为。
# 来源场合：remember 把写下这条时的场合记进 extra.origin（群号 / 私聊 / 控制台），recall 与 search 的行
#   用「文案-来源群 / 文案-来源私聊 / 文案-来源控制台」标出来；印象蒸馏的行用 extra.groups 标成印象来源群；
#   两样都没有的老行如实标「来源未记」，不猜、不编。
# 默认重要度：remember 不给 importance 时用的值（0-10，越界夹到区间内）。
# 列表条数：recall 不给 limit 时最多返回几条。
# 检索条数：search 不给 limit 时最多返回几条。
# 检索放大倍数：库侧多取多少倍再在 Java 侧按作用域过滤（过滤会砍掉一部分，所以先多取）。
# 查重最短长度：归一化后短的一边至少有这么多字，才允许用「包含」判定为同一条。
# 查重取样条数：查重时先从同一个作用域取多少条来比。
# 相似阈值：包含判定都不中时，再按基板 kit/Fingerprint 的中文 2-gram Jaccard 判「近似同一条」
#   （≥ 这个值就当重复）——"换了说法但说的是同一件事"的记忆不会各堆一份。
# 指纹最短项数：内容至少要有这么多 2-gram 项才做近似判定（太短的内容什么都能撞上，宁可不判）。
# 内容长度上限：content 最大字符数；超了直接拒绝。
# 记忆标签：每条记忆都会带上的标签。
# 越权全局降级为个人：true = 非主人写 global 时降级成自己的 user；false = 直接拒。
#   非主人写 global 已被归属硬判拒（MemorySkill 的 guardWriteScope），走不到这一路。
# 时间格式：条目里时间的格式（recall/search 的行现在不带时间时不会渲染）。
# 权限不在这里配：四个动作各判自己的 op（memory.remember / recall / search / forget，技能管控表：
#   空 = 未授权 = 不可用），管数据隔离的仍是技能自己的归属硬判：
#   非主人只能动自己的 user（本人 QQ）与本群的 group；写 global、写/读别人的 user、写别的群、
#   删非本人的记忆一律拒。主人与她本人照常（MemorySkill 的 remember / guardWriteScope / guardReadScope / forget）。
#   要放开只有主人写技能管控表这一个入口（skillctl.json 的 Run/Ban 条目，或她的 perm 工具授权 op）；
#   拒绝文案带 [权限阻断] 标识。
