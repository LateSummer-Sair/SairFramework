# 记忆（工具 `memory`；四个动作各判自己的 op，数据隔离靠技能自己的归属硬判）

长期记忆按**作用域**分开放，落在基板六库的 **`memory` 库**
（`id/ts/scope/scope_id/content/importance/source/tags/extra`），只调 `h.store()`。

**人是跨群的同一人，群只是场合**：关于某个人的事记在他头上（`user` + 他的 QQ），
换个群照样取得到；只在某个群成立的事记在群头上（`group` + 群号），不跟着人跨群跑。

| 作用域 | `scope` | `scope_id` | 放什么 | 谁看得见 |
|---|---|---|---|---|
| 个人 | `user` | QQ | **关于这个人**的事：性格、偏好、称呼、身份、他说过的话、他私下告诉你的事 | 本人；主人与她本人（`SYSTEM`）不受限 |
| 群 | `group` | 群号 | **只在这个群成立**的事：群规、群内约定、群里的梗 | 本群的人；主人与她本人（`SYSTEM`）不受限 |
| 全体 | `global` | 空 | 通用结论 | 所有人 |

`source` = `记忆`，`tags` 含记忆标签，
`extra` 记 `{"hits":n,"by":QQ,"by_name":名字,"origin":{"entry":"qq","group":群号,"session":"group:群号"}}`
—— **`origin` 是"这条是在哪个场合写下的"**，回想时据此标出来源场合。

## 四个 op

### `remember` —— 记一条（op `memory.remember`，**先查重**）
- `content` 必填；`scope` 不填时按主人配的「默认作用域」（**出厂 `user`**）—— 你不用去找那个文件，要改就跟主人说；`scope_id` 不填 = 当前的人 / 当前的群；
- **查重（两道）**：同一作用域内，① 内容归一化后相等、或短的一边 ≥「查重最短长度」且被长的一边包含
  → 命中已有那条；② 都不中时按基板 `kit/Fingerprint` 的中文 2-gram Jaccard 判近似
  （≥「相似阈值」，且内容指纹项数 ≥「指纹最短项数」）—— "换了说法但说的是同一件事"也压得住。
  命中都只把 `extra.hits` 加一、必要时抬高重要度，**不重复堆**；
- **来源场合**：写入时把当时的 `entry/group/session` 记进 `extra.origin`（跨群回想时用来判断"这话能不能在别的群提"）；
- 非主人写 `global`：**一律拒**（带 `[权限阻断]` 标识，`MemorySkill` 的 `guardWriteScope` 归属硬判）；
  「越权全局降级为个人」现在只作用于她自己的自主行为那一路；
- 非主人写**别人的** `user` 作用域、或**别的群的** `group` 作用域 → 直接拒绝；
- 主人那份配置缺「默认作用域」时**直接报缺配置**，不偷偷按某一层记（口径只在配置里 —— 你不用去找那个文件，要改就跟主人说）。

### `recall` —— 回想（op `memory.recall`）
- **不给 `scope`**：分三节返回，每节最多「列表条数」条 ——
  ① **【关于这个人】**（`scope=user, scope_id=当前说话的人`）：**跨群**的记忆，换个群照样取得到；
  ② **【本群】**（`scope=group, scope_id=当前群`）：只在本群成立、不会跨群出现；
  ③ **【全体】**（`scope=global`）。
  每一条都带**来源场合**（写它时在哪个群 / 私聊 / 控制台；印象蒸馏的行标它取样覆盖到的群；
  老行没记过来源就如实标「来源未记」）—— **能不能在别的群提这件事，由你自己按来源判断**；
- **给了 `scope`**：只查那一层；非主人查**别人的** `user`、**别群的** `group` 一律拒（`MemorySkill` 的 `guardReadScope` 归属硬判）。

### `search` —— 全文检索（op `memory.search`）
`Store.search("memory", query, limit × 放大倍数)`（FTS5 优先、LIKE 回退），
**再在 Java 侧按作用域过滤**（`Store.search` 没有 filter 参数）：非主人只看得到 全局 / 本群 / 本人。
行上和 `recall` 一样带来源场合。

### `forget` —— 删（op `memory.forget`）
- 本人自己写的 `user` 记忆（`scope_id == 自己 QQ`）：直接能删（`MemorySkill` 的 `forget` 归属硬判）；
- 其它任何一条（别人的、本群的、全局的）：**只有主人或她本人（`MASTER`/`SYSTEM`）**能删 —— 受限的只有 `ALLUSER`。

## 权限与归属

**两件事分开看**：① 技能管控表判 op（这个动作给不给他用）；② 技能自己的归属硬判（这会动到谁的数据）。

每个动作在分支开头各判一次自己的 op（`memory.remember` / `memory.recall` / `memory.search` / `memory.forget`；
技能管控表里**空** = 没写这条，或写了没给身份 ⇒ **未授权 = 不可用**，**Ban** = 不可用，`Run` = 可用）；
判不过就把基板的拒绝原文原样回给模型。
op 过了之后，归属硬判仍然存在、仍是隔离的主要手段（读口与非本人行仍靠它）：

| op / 场景 | 非主人（`ALLUSER`） | 代码位置（符号名） |
|---|---|---|
| `remember` 自己的 `user` / 本群的 `group` | 放行 | `MemorySkill.guardWriteScope` |
| `remember` `global` | **拒** | `MemorySkill.remember` → `guardWriteScope` |
| `remember` 别人的 `user` / 别的群 | **拒** | `MemorySkill.guardWriteScope` |
| `recall` / `search` 自己的 `user`、本群的 `group`、`global` | 放行 | `MemorySkill.guardReadScope` / `MemorySkill.visible` |
| `recall` 别人的 `user` / 别群的 `group` | **拒** | `MemorySkill.guardReadScope` |
| `forget` 自己的 `user` 记忆 | 放行 | `MemorySkill.forget` |
| `forget` 其它任何一条 | **拒**（只有主人或她本人） | `MemorySkill.forget` → `restricted` |

主人（`MASTER`）恒全权；她自己的自主行为（`SYSTEM`）照常 —— 两人都不受技能管控表影响。
要放开只有主人写表那一个入口（数据根 `skillctl.json` 的 `Run`/`Ban` 条目，或她用 `perm` 工具的授权 op），
例如 `Run["memory.remember","ALLUSER"]` = 允许所有人记一笔（归属硬判照旧管着"能记到谁头上"）。
拒绝文案统一带 `[权限阻断]` 标识（**值同** `Acl.DENY_PREFIX`；技能里用常量 `DENY` 钉住，不随配置变）：
**前缀**由代码保证，**理由句**由归属硬判自己拼（`MemorySkill.blocked(...)`），不走 `prompt.md`。

## 记什么 / 不记什么
- 记：长期成立的事实与偏好（"他在上海""这个群不聊政治""接口超时先看连接超时"）；
- 不记：一次性的闲聊、口令、当下就能从上下文读到的东西、别人的隐私细节；
- 选作用域：**关于这个人的** → `user`（他换个群你还认得出、接得上）；
  **只在这个群成立的** → `group`（跟群走，不跟人跨群跑）。拿不准就按"是不是关于他这个人"来判；
- 记之前先 `search` 一下，别把同一件事记成三条 —— 查重只是兜底，不是让你随便记。
- 要记"AI 被纠正"用 `correct`；要记"知识/经验"用 `note`；要记"设定"用 `pref`。这里放**事实与经历**。
