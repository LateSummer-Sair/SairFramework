# 好友管理（工具 `friend`：每个动作一个 op，能不能用看技能管控表）

好友列表 / 用户资料查询 + **机器人自己账号**上的动作（删好友、拉黑、点赞、戳一戳、改昵称/签名）。
平台动作全部经 `h.napcat()` 发出；
**未连接 NapCat 时一律返回基板话术「Napcat 没有连接」**，不抛异常。
唯一的例外是 `block` / `unblock` / `blocklist`：**本地黑名单完全不依赖 NapCat**，未连接也照样生效。

## op 表

| op | NapCat 动作 | 权限（技能管控表里的 op） | 说明 |
|---|---|---|---|
| `list` | `get_friend_list` | `friend.list` ＋ `napcat.get_friend_list` | 好友列表（QQ/昵称/备注），「好友列表最多」截断 |
| `info` | `get_stranger_info`（无 group）/ `get_group_member_info`（有 group） | `friend.info` ＋ `napcat.get_stranger_info` / `napcat.get_group_member_info` | 陌生人资料 / 群成员详情 |
| `delete` | `delete_friend` | `friend.delete` ＋ `napcat.delete_friend` | 删除好友 |
| `block` | 本地 `kv:block:<qq>` ＋ `prompt.md` 的「拉黑动作」 | `friend.block`（＋归属硬判；平台动作另判 `napcat.<拉黑动作>`） | 拉黑：**先写本地黑名单**，再尽力发平台动作 |
| `unblock` | 删本地 `kv:block:<qq>` ＋「解除拉黑动作」 | `friend.unblock`（＋归属硬判；平台动作另判 `napcat.<解除拉黑动作>`） | 解除拉黑（本地删掉即恢复触发） |
| `blocklist` | **无平台动作**（纯本地读） | `friend.blocklist` ＋归属硬判（非主人一律拒，拒绝文案里不带名单内容） | 看本地黑名单里有谁（NapCat 侧看不到这份名单） |
| `like` | `send_like` | `friend.like` ＋ `napcat.send_like` | 点赞，「默认点赞次数」缺省 |
| `self` | `get_login_info` | `friend.self` ＋ `napcat.get_login_info` | 机器人自己的账号（QQ/昵称） |
| `poke` | `group_poke`（有群号）/ `friend_poke`（无群号） | `friend.poke` ＋ `napcat.group_poke` / `napcat.friend_poke` | 戳一戳：群里带 group_id，私聊只带 user_id |
| `rename` | `set_qq_profile`（只发 nickname） | `friend.rename` ＋ `napcat.set_qq_profile` | 改机器人自己的 QQ 昵称 |
| `signature` | `set_self_longnick` | `friend.signature` ＋ `napcat.set_self_longnick` | 改机器人自己的个性签名 |

> 每一行都要**两道都过**：① 技能自己那个 op（`friend.<动作>`，判在动作分支开头）；
> ② 真正发出去的那个 NapCat 动作（`napcat.<动作名>`，判在 `FriendSkill.act`）。
> 表里没放行 = 未授权 = 不可用；`MASTER` 与她本人 `SYSTEM` 恒全权。

## 两套"拉黑"：本地是权威，平台是尽力（重要）

**为什么要有本地那一套**：QQ 层面的拉黑/删好友**管不到群内互动** ——
NapCat 没有"群内屏蔽某人"这类动作，对方被你在 QQ 上拉黑了，**照样能在群里 @ 机器人**。
所以本地黑名单补的就是这一刀：

| | 本地黑名单（权威） | 平台动作（尽力） |
|---|---|---|
| 存哪 | kv 键 `block:<qq>`（存在且值非空 = 已拉黑；值 `{reason,at,by}`） | NapCat 动作，名字读 `prompt.md` |
| 谁读 | **基板入站网关**（`QqGateway.blocked`）＋ 本技能 `blocklist` | QQ 客户端 |
| 效果 | 这个人的消息**不触发 AI**（私聊与群内**一视同仁**）；消息本身**照旧记进 grouplog** 留痕，日志里写明「本地黑名单：已拉黑，不触发」 | 尽力让 QQ 侧也拉黑（对方视角） |
| 失败了怎么办 | 写失败时返回「本地黑名单没写进去…这一条没生效」，并且**不发平台动作**（别做半套） | 没配动作名 / 不支持 / 没连接 → **不回滚本地**，原因原样拼进 `{act}` |

```
拉黑动作: set_friend_block        # 你的 NapCat 构建支持什么就填什么；留空 = 只做本地
解除拉黑动作: set_friend_block
```

- **先写/删本地黑名单，再发平台动作**；返回文案里的 `{act}` 就是平台那一步的结果
  （「平台动作已执行」/「未配置，跳过」/ NapCat 原样错误）。
- NapCat 的 OneBot v11 动作目录里**没有**"屏蔽好友"这一类动作（`Api.catalog()` 也没有），
  所以动作名是配置项；出厂值 `set_friend_block` 只是命名上最接近的猜测。
- 想知道本地到底拉黑了谁：`friend op=blocklist`（**只有这条路能看到**，QQ 那边看不到本地名单）。

## 权限口径

1. **能不能用**只看技能管控表（数据根 `skillctl.json`）：本技能 11 个 op（`friend.list` / `friend.info` /
   `friend.delete` / `friend.block` / `friend.unblock` / `friend.blocklist` / `friend.like` / `friend.self` /
   `friend.poke` / `friend.rename` / `friend.signature`），每个动作在分支开头判自己那一个
   （`h.need("friend.<动作>")`，拒文原样回给模型）。`Run` 白名单 = 可用、`Ban` 黑名单 = 不可用、
   **空 = 未授权 = 不可用**；`MASTER` 与她本人（`SYSTEM`）恒全权。
2. 每个 op 都要发 NapCat 动作，所以**发动作前还要判那个动作自己的 op**：`h.need("napcat.<动作名>")`
   （`FriendSkill.act`）。非主人默认拿不到（**空 = 未授权**），回基板那句带 `[权限阻断]` 的原文
   （技能不自己编）；要放开只能由主人往表里写身份，例如给某个人放行 `friend.like` + `napcat.send_like`
   = 只给这个人点赞。她读事实块时看的是 `caller.ops`（这个身份能用的技能 / 动作清单；
   `"ALL"` = 全权、`[]` = 一个都没有）。
3. `block` / `unblock` / `blocklist` 另有一道**归属硬判**（`FriendSkill.ownerDeny` /
   `FriendSkill.readOwnerDeny`：`MASTER` 与 `SYSTEM` 照常放行，`ALLUSER` 一律拒）：本地黑名单是一份
   **全局共享**的名单（kv 键 `block:<qq>` 里只有"被拉黑的人"，没有"谁拉的"这一维度），
   技能管控表只回答"能不能用这个动作" ⇒ "谁能改 / 谁能看这份名单"仍由技能自己硬判（归属判定，不是 op）。
4. 本地那一半落在通用 kv 表：op 授权过了、归属硬判过了就写，技能里不再有第二道资源判定。
5. `rename` / `signature` 改的是机器人自己的账号资料，`delete` / `like` / `poke` 同样是对外动作
   —— 都走上面同一条 op 判定链，没有额外的主人专属键。

## 配置与文案

全在同目录 `prompt.md`（运行期读，改即生效）：`启用`、`默认点赞次数`、`好友列表最多`、`黑名单最多`、
`时间格式`、`拉黑动作`、`解除拉黑动作`，以及全部输出文案与模板（含 `{act}` 平台动作结果占位）。
值留空 = 用技能里的结构性 ASCII 兜底。

## 典型用法

```
friend op=list                       # 好友列表
friend op=info qq=10001              # 陌生人资料
friend op=info qq=10001 group=123456 # 这个人在群里的名片/角色
friend op=self                       # 我自己的账号
friend op=like qq=10001 times=10     # 点赞
friend op=delete qq=10001            # 删好友（非主人默认拒；她本人 SYSTEM 照常）
friend op=block qq=10001 reason=广告 # 拉黑：本地黑名单（权威）+ 尽力发平台动作
friend op=blocklist                  # 本地黑名单里有谁（仅主人与她本人 SYSTEM）
friend op=unblock qq=10001           # 解除拉黑（本地删掉即恢复触发）
friend op=poke qq=10001              # 戳一戳（当前群）
friend op=poke qq=10001 group=123456 # 戳某个群里的人
friend op=rename name=椰羊            # 改机器人昵称（非主人默认拒；她本人 SYSTEM 照常）
friend op=signature signature=你好呀   # 改机器人签名（同上）
```
