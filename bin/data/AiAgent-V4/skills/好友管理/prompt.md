# 好友管理 · 配置与文案
# 本文件是「好友管理」技能的配置源：保存即生效（基板监听技能目录，自动热重载）。
# 格式：一行一条「键: 值」；# 开头的行是注释；值为空 = 该键用技能里的结构性 ASCII 兜底。

# ---- 配置 ----
启用: true
默认点赞次数: 10
好友列表最多: 200
黑名单最多: 100
时间格式: yyyy-MM-dd HH:mm
# 拉黑动作 / 解除拉黑动作：NapCat 标准动作目录里没有"屏蔽好友"，所以动作名做成配置项。
# 你的 NapCat 构建支持什么就填什么；填错了动作会失败并原样把 NapCat 的原因返回给模型。
# 注意：本地黑名单（kv 键 block:<qq>）才是权威 —— 入站网关据此不触发 AI（群内也拦得住）。
# 平台动作只是尽力而为：留空 = 只做本地，不报错。
拉黑动作: set_friend_block
解除拉黑动作: set_friend_block

# ---- 文案 ----
未启用: 好友管理技能在 prompt.md 里被关掉了（启用: false）。
执行异常: 好友管理执行出错：{err}
缺参数: 缺少参数 {k}，请补上再调用。
不支持的操作: 不支持的 op「{op}」。可用：{ops}
权限不足: {deny}
操作失败: {op} 失败：{err}
未配置动作: prompt.md 里的「{k}」是空的，{op} 用不了 —— 先填上你的 NapCat 实际支持的动作名。
本地写入失败: 本地黑名单没写进去（六库写入失败），这一条没生效。
平台动作-未配置: prompt.md 的「{k}」是空的，平台动作跳过（本地黑名单已生效）。
平台动作-已执行: 平台动作已执行
好友表头: 我有 {n} 个好友：
好友行: {i}. {qq}｜{name}｜备注 {remark}
陌生人详情: {qq}｜昵称 {name}｜性别 {sex}｜年龄 {age}｜等级 {level}
成员详情: 群 {group} 里的 {qq}｜昵称 {name}｜名片 {card}｜角色 {role}｜等级 {level}
账号信息: 我的账号：{qq}（{name}）。
已删除好友: 已删除好友 {qq}。
已拉黑: 已拉黑 {qq}（本地黑名单已记录，他的消息不会再触发我；平台动作：{act}）
已解除拉黑: 已解除对 {qq} 的拉黑（本地黑名单已清除，他的消息又会触发我；平台动作：{act}）
黑名单头: 本地黑名单里现在有 {n} 人（平台侧看不到这份名单）：
黑名单行: {i}. {qq}｜{time}｜{reason}｜by {by}
黑名单空: 本地黑名单是空的。
已点赞: 已给 {qq} 点赞 {times} 次。
已戳群: 戳了群 {group} 里的 {qq} 一下。
已戳私聊: 戳了 {qq} 一下。
已改昵称: 我的昵称已改成「{name}」。
已改签名: 我的个性签名已更新：{sig}
截断说明: （共 {n} 条，只列了前 {shown} 条）

# ---- 说明 ----
# 默认点赞次数：like 没给 times 时用（NapCat 单次点赞有上限，一般 10 次左右）。
# 好友列表最多 / 黑名单最多：一次最多列多少行，超出补一行「截断说明」。
# 时间格式：黑名单行的 {time} 用它是格式化。
# 拉黑/解除拉黑：先写/删本地黑名单（权威），再尽力发平台动作；平台失败不回滚本地。
#   {act} = 平台动作那一步的结果（已执行 / 未配置，跳过 / 或 NapCat 原样错误）。
#   {by} = 拉黑是谁下的手（QQ 号，V3 迁移来的是 blocked_by）。
# 占位符：{i} 序号 {n} 总数 {shown} 已显示条数 {qq} QQ号 {name} 昵称 {remark} 好友备注
#   {sex} male/female/unknown {age} 年龄 {level} 等级 {group} 群号 {card} 群名片 {role} 群角色
#   {action} 实际发出的 NapCat 动作名 {times} 点赞次数 {op} op 名 {ops} 可用 op 清单
#   {sig} 新签名 {act} 平台动作结果 {time} 拉黑时间 {reason} 拉黑原因 {by} 拉黑发起者
#   {k} 缺的参数名或空的配置键 {err} 失败原因 {deny} 基板权限文案
