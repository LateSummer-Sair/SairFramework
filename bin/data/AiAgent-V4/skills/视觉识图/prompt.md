## 文案
兜底说明: 你是视觉观察员。看清这张图里有什么，用文字完整描述（主体、文字内容、关键细节、可能的含义），不要臆造没看到的东西。
兜底任务: 看这张图并回答：{ask}（图片：{url}）
兜底失败: 视觉兜底失败（模型 {model}）：{error}
结果: {text}
结果元信息: —— 来源 {image}，模型 {model}，耗时 {ms}ms{extra}
缓存标记: （命中缓存，{age} 分钟前的同一次提问）
黑名单: 这张图之前已经明确失败过（{reason}），不再重试；确实要再试一次就在 see 里带 refresh=true。
无key: 模型没配 apiKey，看不了图。请让主人填好 config.json 里的 apiKey（apiUrl={apiUrl}）再试。
缺图片: 要我看哪张图？给我 image（http 链接、数据目录里的本地路径，或 NapCat 的 fileid）。
越界: 这个路径在数据目录之外（{path}），视觉识图只读数据目录里的图片。
图片不存在: 数据目录里没有这个文件：{path}
读不了: 这个文件读不出来（{error}）。
太大: 图片太大（{size} 字节，上限 {max} 字节），先压小或换一张。
格式不支持: 认不出图片格式（{path}），支持 png / jpg / gif / webp / bmp。
fileid取不回: NapCat 没能把这张图取回来：{error}
内网拒绝: 这张图的地址指向内网（{host} · {reason}），按安全口径不读：{image}
读不到临时: 这张图这次没取回来：{error}（不算永久失败、没拉黑，可以稍后重试或改传图片链接）。
模型失败: 模型没看成：{error}
空结果: 模型没给出内容（这个模型可能不支持图片输入，试试在 prompt.md 里配 视觉模型）。
不支持op: 不支持的 op：{op}（只支持 see）。
异常: 执行异常：{error}

# 说明
# 启用缓存：on / true / 1 才算开；关掉就每次都打模型（黑名单仍然生效）。
# 缓存小时：同一张图 + 同一个问题的结果保留多久（0 = 永不过期）。
# 最大图片字节：本地图片超过这个大小直接拒绝（base64 后还会涨约 1/3，别设太大）。
# 视觉模型：留空 = 用基板模型；填了会覆盖这次请求的 model 字段（例如填一个支持图片的模型名）。
# 默认提示词：调用时没给 prompt 就用它。
# 内网拒绝：图片地址过不了基板 SSRF 闸门（kit/NetGuard）时的说明；{host} 主机、{reason} 类别、{image} 原地址。
# 读不到临时：**临时失败**的说明（比如 NapCat 与插件不同机，get_image 给的是 NapCat 那台机器的路径）。
#   临时失败不进 vision:bad: 黑名单 —— 换台机器、等缓存落盘、改用图片 URL 都可能救回来。
