# 群管理 · 配置与文案
# 本文件是「群管理」技能的配置源：保存即生效（基板监听技能目录，自动热重载）。
# 格式：一行一条「键: 值」；# 开头的行是注释；值为空 = 该键用技能里的结构性 ASCII 兜底。
# 注意：技能里没有任何写死的中文文案 —— 模型看到的一切文字都来自这里。

# ---- 群管口径（什么时候该做、什么时候先别做）----
# 群管动作（禁言/踢人/改名/全员禁言/改名片/设管理员/退群解散）都是对外动作（E 类）：非主人提的（含群主、管理员）一律只回「这得主人定」；主人提的说清后果再动手。
# 非主人提的一律不执行；可以看上下文（理由、是不是同一个人反复来提、对群氛围有没有好处）决定要不要顺手报给主人，拿不准就问主人。
# 退群、删好友、拉黑不算「执行」，动的是你自己的社会资源（群、好友、名片都算你的），默认更保守：理由不足就别做，宁可回「这个我拿不准」；真想做又拿不准就先问主人。
# 问主人的形态：控制台或私聊留一句 —— 请求 + 理由 + 你打算怎么做（默认动作）；主人不回就按最保守的选项走（一般是不做）；
#   同一件事短期内只问一次，别反复催。

群列表头: 我加入了 {n} 个群：

# ---- 说明 ----
# 默认禁言秒数：ban 没给 duration 时用；duration=0 = 解除禁言。
# 踢人默认拉黑：kick 没给 reject 时用；true = 踢出去并拒绝对方再加群。
# 退群默认解散 / 解散需主人：dismiss 缺省值；解散另过 set_group_leave 的 E 位，非主人一律拒。
# 群列表最多 / 成员列表最多：一次最多列出多少行，超出会补一行「截断说明」。
# 占位符：{i} 序号 {n} 总数 {shown} 已显示条数 {group} 群号 {qq} QQ号 {name} 群名或昵称
#   {card} 群名片 {role} owner/admin/member {level} 成员等级 {count} 成员数 {max} 成员上限
#   {sec} 秒数 {enable}/{reject}/{dismiss} true|false {title} 专属头衔 {join} 入群时间
#   {op} op 名 {ops} 可用 op 清单 {k} 缺的参数名 {err} 失败原因 {deny} 基板权限文案
