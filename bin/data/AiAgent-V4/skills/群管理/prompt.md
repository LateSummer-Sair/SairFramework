# 群管理 · 配置与文案
# 本文件是「群管理」技能的配置源：保存即生效（基板监听技能目录，自动热重载）。
# 格式：一行一条「键: 值」；# 开头的行是注释；值为空 = 该键用技能里的结构性 ASCII 兜底。
# 注意：技能里没有任何写死的中文文案 —— 模型看到的一切文字都来自这里。

# ---- 群管口径（什么时候该做、什么时候先别做）----
# 群管动作（禁言/踢人/改名/全员禁言/改名片/设管理员/退群解散）都要过技能管控表：非主人提的（含群主、管理员）没被授权就一律只回「这得主人定」；主人提的说清后果再动手。
# 非主人提的一律不执行；可以看上下文（理由、是不是同一个人反复来提、对群氛围有没有好处）决定要不要顺手报给主人，拿不准就问主人。
# 退群、删好友、拉黑不算「执行」，动的是你自己的社会资源（群、好友、名片都算你的），默认更保守：理由不足就别做，宁可回「这个我拿不准」；真想做又拿不准就先问主人。
# 问主人的形态：控制台或私聊留一句 —— 请求 + 理由 + 你打算怎么做（默认动作）；主人不回就按最保守的选项走（一般是不做）；
#   同一件事短期内只问一次，别反复催。

# ---- 边缘能力口径（NapCat 4.18：群待办 / 群打卡 / 群成员策略 / 群分享链接 / 群相册 / QQ 空间）----
# 这十个动作和群管动作一个规格：都过技能管控表，没被授权就回基板的拒绝原文、动作不发。
# 高危写类（完成/取消群待办、三个群成员策略、取消相册点赞、删空间说说）与对外发声（发空间说说）默认只给主人：
#   非主人（含群主、管理员）一把都用不了；就算管控表里给某个身份放开了技能这一层，动作本身还有第二道闸（napcat.<动作名>）。
# 还要一次显式确认：高危需确认 开着时，这些动作要带 confirm=true 才动手（见下方「需二次确认」）。
#   缺确认时不要自己补一个 true 硬发 —— 先把后果说给提要求的人听，他确认了再带 confirm=true 叫一次。
# 「完成/取消群待办」挂在一条消息上：必须给 msg（那条消息的 message_id），别猜、别随便挑一条。
# 「群成员邀请策略」是公开姿态：disabled / require_approval / no_approval / no_approval_under_100，
#   改的是「群成员能不能拉人进群、要不要管理员审核」—— 改之前先说清它会让谁进得来。
# 「新成员历史消息可见性」动的是所有人的旧聊天记录对新人的可见范围：只在本群确实需要时改，改完告诉群里。
# 「取消点赞群相册」不可撤销地抹掉你自己在那批媒体上的点赞（album + batch 必给；lloc 只针对单张媒体）。
# 群打卡名单与群分享链接是读类：查得到就照实说；链接是加群入口，别往无关的群里贴。

# ---- QQ 空间（不是群消息！）----
# ★★ 空间说说对外公开可见：默认 ugc_right=1（所有人可见），删要凭 tid。它不是群消息，别当群消息发。★★
# 只有主人能让你发（默认权限；非主人提的一律只回「这得主人定」）。发之前先想：这条会不会被不认识的人看到、
#   里面有没有只该群里知道的事；拿不准就先问主人。
# 出站纪律照旧：这条正文同样过基板的内容闸（出站红线 / 标记族 / 内部事实行 / 自我记账头）。
#   被拦了就是没发出去 —— 别换个说法硬凑，也别把内部事实行、[[mood:…]] 标记当正文塞进去。
# 图片只收 http:// 或 https:// 地址（本地路径交出去跨机读不到）；空间图片 URL 约 2 小时过期，别把旧链接存起来复用。
# 可见范围别随手放宽：部分好友可见（16 / 128）必须同时给 targets（QQ 号列表）。

# ---- 说明 ----
# 默认禁言秒数：ban 没给 duration 时用；duration=0 = 解除禁言。
# 踢人默认拉黑：kick 没给 reject 时用；true = 踢出去并拒绝对方再加群。
# 退群默认解散 / 解散需主人：dismiss 缺省值；解散时会把同一个 op（group.leave）再判一遍，没授权一律拒。
# 群列表最多 / 成员列表最多 / 打卡名单最多：一次最多列出多少行，超出会补一行「截断说明」。
# 高危需确认：true = 高危写类与空间发布必须带 confirm=true；false = 不要求确认（权限口径不变）。
#   这一道不是权限门槛（权限只有技能管控表那一道），只是「不可撤销 / 对外可见」动作的一致性闸。
# 分享默认短链：sharelink 没给 short 时用；true = need_short_url 短链，false = 完整 universal-share 链接。
# 空间默认可见范围：qzonesend 没给 right 时用；1 所有人 / 4 好友 / 16 部分好友 / 64 仅自己 / 128 部分好友不可见。
#   要收紧成「只自己可见」就把这里改成 64（默认 1 跟上游 NapCat 的默认值一致）。
# 占位符：{i} 序号 {n} 总数 {shown} 已显示条数 {group} 群号 {qq} QQ号 {name} 群名或昵称
#   {card} 群名片 {role} owner/admin/member {level} 成员等级 {count} 成员数 {max} 成员上限
#   {sec} 秒数 {enable}/{reject}/{dismiss}/{visible} true|false {title} 专属头衔 {join} 入群时间
#   {op} op 名 {ops} 可用 op 清单 {k} 缺的参数名 {err} 失败原因 {deny} 基板权限判定原文
#   {v} 不合法的取值 {opts} 可用取值 {msg} 消息 ID {policy} 邀请策略
#   {facts} 这次改动的项（如 upload_album=true） {url} 分享链接 {batch} 相册批次 {lloc} 单张媒体
#   {right} 空间可见范围 {chars} 正文字数 {images} 图片张数
