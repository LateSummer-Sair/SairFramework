# 触发词（工具 trigger）· 配置与文案
# 本文件是本技能唯一的阈值与文案来源：工具调用与 on_message 钩子都每次重读它 —— 改这里即时生效。
# 格式：一行一条「键: 值」；# 开头的行是注释；空行忽略。
# 值里的 \n 会还原成换行；{xxx} 是占位符，由技能按上下文渲染。
# 缺任何一个键，对应路径会明确报「缺键」或直接不动作（不猜、不用隐藏默认值）。
#
# 默认保守（被动优先）：出厂**词表是空的**（词条存在 kv 里，只有主人 set 过才有），
#   所以没人提及、没配触发词时钩子什么都不做，也不会触发回合 —— 这就是出厂行为，
#   不需要额外开关。要它主动，是主人显式 trigger set 一个词的事。

## 配置（阈值）
冷却秒: 30
被艾特时让位: true
私聊时让位: true
触发词长度上限: 40
最多触发词: 50
列表上限: 30

## 文案（面向模型/用户）
不支持op: [trigger] 不支持的 op：{op}（只支持 {ops}）
异常: [trigger] 操作失败（{op}）：{error}
触发词太长: [trigger] 触发词太长（{size} > {limit} 字）：{word}
触发词太多: [trigger] 触发词已达上限（{limit} 个），先 remove 掉不用的。
已设置: 已设置触发词「{word}」。{note}共 {count} 个触发词。
没有设置: 没有设置任何触发词。{note}当前共 {count} 个触发词。
已删除: 已删除触发词「{word}」。
已清空: 已清空 {count} 个触发词。
没有这个触发词: 没有触发词「{word}」。
列表空: 还没有触发词。用 op=set 设一个（word=关键词，可逗号分隔）。
列表头: 触发词 {count} 个
列表项: {i}. 「{word}」用过 {uses} 次{last}\n    {prompt}\n    工具：{tools}
列表还有: …（还有 {rest} 个未列出）
全部工具: 主 Agent 全部工具
最后使用: （上次 {time}）
触发_说明默认: 有人说到了「{word}」：{name}({qq}) 在群 {group} 说「{text}」。请你以机器人的身份自然接一句，别复述原话、别说“我注意到”。只输出要发出去的那句话本身：不要写说明、不要报任务号/工具名/调度过程、不要调用任何发送工具（基板会把你写的这句话发出去）；不想接就只回 <silent>。
冷却中: 命中「{word}」但还在冷却（还有 {left} 秒），这条交回基板判定
已接管: 命中「{word}」→ 已派给主 Agent 接话（{status}）
让位: 这条是直接找机器人的（被 @ / 私聊），交回基板，不抢
已接管过: 这条已经被别的技能接管了（_handled=true），不重复处理
缺配置: 缺少配置「{key}」，本技能不动作
时间格式: yyyy-MM-dd HH:mm

## 说明
# set / remove 是敏感 op：代码里先做归属硬判（MASTER / SYSTEM 放行，ALLUSER 一律拒，
#   拒绝文案带 [权限阻断] 标识）。list 只读通用 kv 表（C 类 R 位，默认就有），没有身份门槛。
# 没有设置：一个词都没真的落库（全超长、或已达「最多触发词」）时的回执 —— 那时候不能说"已设置"；
#   {note} 是逐条原因（触发词太长 / 触发词太多），{count} 是词表当前总数。
# 冷却秒：同一个会话里同一个触发词两次接话之间的最小间隔（0 = 不冷却）；冷却期内也不回（投一票"别自动回"）。
# 让位（出厂两条都是 true）= 这几类消息交给基板正常回，技能不抢：
#   被艾特时让位：@ 了机器人 → 让位（基板本来就会回）。
#   私聊时让位  ：私聊消息 → 让位（私聊没有"@"这一说，要能在私聊里跟它说话、吩咐它改触发词）。
# 两条都不满足时（群里没 @、也不是私聊）：只有**命中触发词**才回；没命中就投 _reply=false，
#   基板直接结束这条（不建上下文、不调模型）—— 这就是"其他情况可以不响应"和省 token 的落点。
# 注意：**主人不再特殊**：主人说话跟别人一样走上面三条规则（以前"主人说话就让位"的口径已删除）。
