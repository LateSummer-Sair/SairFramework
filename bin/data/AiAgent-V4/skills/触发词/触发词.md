# 触发词（工具 `trigger`，钩子 `on_message`：`set`/`remove` = 归属硬判，`MASTER` 与 `SYSTEM` 放行、`ALLUSER` 一律拒）

"说到这些词就接一句"——一份词表 + 一个消息钩子。**技能自己不回消息**：命中后把接话这件事
`h.spawn(接话说明, 工具白名单, true, …, reply=true)` 交给主 Agent（`reply=true` = 子 Agent 写成的那句话
由宿主替她发回原会话），并置 `payload._handled = true`，基板不再自动回复（避免双重回复）。

## 三个 op

### `set`（**仅主人**：`MASTER` 与她自己的自主行为 `SYSTEM`）
**归属硬判**（`TriggerSkill` 的 `ownerDeny`：`MASTER` 与 `SYSTEM` 放行，`ALLUSER` 一律拒 ——
词表是一份**全局共享**的表，没有"谁的词"这一维度），不过就返回带 `[权限阻断]` 标识的拒绝文案。
- `word` 必填，可逗号分隔一次设多个；
- `prompt`（接话说明模板）与 `tools`（子 Agent 工具白名单）可选，留空 = 用 `prompt.md` 的默认模板 / 主 Agent 全部工具；
- 同一个词重复 `set` = 覆盖（`uses` 次数保留）；
- 比 `触发词长度上限` 长的词会被**跳过**、到 `最多触发词` 之后不再收（各自回一行原因）；
  **一个词都没真的落库时回执不说"已设置"**，回的是 `prompt.md` 的「没有设置」+ 原因。

### `list`
列出整张词表：词、用过几次、上次使用时间、说明模板（未设则显示默认模板）、工具白名单。读的只是通用 kv 表（C 类的 `R` 位，默认就有），没有身份门槛。

### `remove`（**仅主人**：`MASTER` 与 `SYSTEM`）
同 `set` 的归属硬判（`ALLUSER` 一律拒）；`word` 给词，或 `all=true` 清空整张表。

## 消息钩子怎么走（`on_message`）
```java
if (payload._handled) return;                     // 已经被别的技能接管
if (@了机器人 && 被艾特时让位=true)  return;         // 让位：基板立刻回
if (私聊      && 私聊时让位=true)   return;         // 让位：私聊是"直接跟它说话"的通道
命中任一触发词（大小写不敏感的子串匹配）？
  冷却期内 → payload._reply=false（这条不回，也不调模型）
 不命中   → payload._reply=false（同上）
 命中     → h.spawn(接话说明, 工具白名单, true, …, reply=true); payload._handled = true;
            // reply=true：子 Agent 写成的那句话由**宿主**发回原会话（它自己发过就不重复发）
```
**三种情形（出厂口径）**：

| 消息 | 谁回 | 为什么 |
|---|---|---|
| 群里 **@ 了机器人** | 基板立刻回 | 明确点名，必须响应 |
| **私聊**（任何内容，含只发图） | 基板立刻回 | 私聊没有"@"这一说；也是主人吩咐它改配置的通道 |
| 群里 **没 @** | 只有**命中触发词**才回（技能派子 Agent 接话） | 其他情况 `_reply=false`：**不建上下文、不调模型** —— 省 token 就省在这里 |
| 主人说话（群里没 @、也没触发词） | **一样不回** | 主人不再特殊："不要每次都回复我" |

- **让位**（`被艾特时让位` / `私聊时让位`，出厂都是 `true`）：这两类消息不抢，交回基板立刻回。
  想让"私聊也必须带触发词"，把 `私聊时让位` 改成 `false` 即可（一行配置）。
- **冷却**（`冷却秒`，按"会话 + 词"计）：冷却期内命中也**不回**（同样投 `_reply=false`）——
  既省 token，也不会重复接话。`0` = 不冷却。
- 冷却键在 kv（`trigger:c:<会话>:<词>`），重启不清零。
- 基板怎么认这一票：见 `sair.v4.QqGateway`（`_handled` = 我接管了，不再自动回；
  `_reply=false` = 这条别自动回；`_reply=true` = 即使没被 @ 也回）。
- **触发词在聊天里就能改**：主人对 AI 说「以后有人提到 XX 你就接一句」，
  模型会调本技能的 `set`（`op=set word=XX`）；「看一下触发词表」= `list`，「把那个触发词删了」= `remove`。
  改完即时生效（词表在 kv，钩子每次都重读），**不需要手动改任何文件**。

## 存储（kv）
| 键 | 内容 |
|---|---|
| `kv.trigger:w:<词小写>` | 词条 JSON：`{word, prompt, tools, ts, by, uses, last_used}` |
| `kv.trigger:c:<会话>:<词>` | 上次派发时间戳（冷却用） |
| `kv.trigger:last` | 最近一次接管记录：`{ts, word, group, qq, name, text, spawn}` |

## 阈值与文案在哪
全部在同目录 `prompt.md`（`冷却秒`、`被艾特时让位`、`触发词长度上限`、`最多触发词`、`列表上限`、
以及全部对外文本与默认接话模板）。工具与钩子**每次**都重读它，改完即时生效；
缺键时明确报 `prompt.md missing …`，或钩子干脆不动作 —— 不猜、不用隐藏默认值。

## 默认保守（被动优先）
出厂**词表是空的**：词条只存在 kv（`trigger:w:*`），而 kv 里没有词 —— 于是群里只有 @ 它才会回，
**其他群消息一条都不响应**（每条都被投 `_reply=false`，基板连模型都不调）；私聊照常回。
主人 `trigger set <词>` 配好触发词之后，含那个词的群消息也会被接（由技能派子 Agent 处理）。
`prompt.md` 缺 `被艾特时让位` / `冷却秒` 时，钩子同样只记一句「缺配置」然后不动作（不猜、不兜底）。

## 与 `主动接话` 的分工
`主动接话` 是"没被点名时要不要**插一句**"的策略技能（命中关键词 → 只注入 context，从不发消息；
出厂 `启用: false`）；`触发词` 是**明确词表**：命中就派主 Agent 真的接话（异步派发，
`reply=true` —— 子 Agent 写成的话由**宿主**发回原会话，不是"回灌结论"），
并且由主人配置。两个可以同时装，各管各的判定，都不会绕过基板自动回复逻辑。
