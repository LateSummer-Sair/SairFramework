# 保存即生效（技能每次调用都重读本文件，不需要重启）；Java 只留**读不到配置时的兜底值/兜底文案**，
# 阈值与口径一律以本文件为准（读不到本文件时才落回 Java 里那份兜底）。
# 格式：`键: 值` 一行一条；`#` 开头的行是注释；行内第一个冒号（或全角冒号）是分隔符，值里可以再带冒号。

## 文案
# 这些是技能面向用户/模型说出来的话；占位符由 Java 替换。某一行删掉时，技能只回结构性结果（不会崩）。
文案-已标记: 已标记 {target} → {mark}（{time}）
文案-已清除: 已清掉 {target} 的标记。
文案-本来就没有: {target} 上本来就没有标记。
文案-一条标记: "{target}" → {mark}　备注：{note}　标的：{by}　时间：{time}
文案-无标记: "{target}" 上没有标记。
文案-条目头: 现有 {n} 个标记：
文案-条目头查: 匹配「{query}」的标记 {n} 个：
文案-条目行: {i}. {target} → {mark}　备注：{note}　{time}　标的：{by}{legacy}
文案-无条目: 现在没有任何标记。
文案-没有匹配: 没有匹配「{query}」的标记。

文案-迁移完成: 迁移完成：扫了 {n} 条，已升级 {up} 条，保留 legacy {lg} 条，未变 {kept} 条。

文案-写入失败: kv 写不进去，标记没生效。
文案-无库: 拿不到六库接口，技能不可用。
文案-未知op: 不支持的 op：{op}（只支持 set / get / list / migrate）
文案-执行异常: 执行异常：{error}

## 备注（不解析）
# 键前缀：kv 里一条标记的键 = 键前缀 + <会话>/<target>（按会话隔离）。改前缀等于换一个命名空间（旧标记仍然在库里，只是列不出来）。
#   **隔离单位是"会话"，不是"人"**：同一个群里的人共用 `group:<群号>` 前缀 ⇒ 同群的人互相 list 得到本会话的标记；
#   跨会话（别的群、私聊）才互相看不到。这是键拼装的必然结果，不是管控表能改的。
# 列表条数：list 不给 limit 时最多列几条。
# 键长度上限：键前缀 + target 的总长度上限；超了直接拒绝（避免写出一个谁也对不上的巨键）。
# 标记长度上限 / 备注长度上限：mark / note 会被截到这个长度，防止模型把整段对话塞进标记。
# 时间格式：条目里时间戳的格式。
# 权限不在这里配：四个 op（mark.set / mark.get / mark.list / mark.migrate）各自在动作分支开头判一次；
#   判定看技能管控表 data/skillctl.json（op 放行才动手；Ban / 空 = 不可用），事实块 caller.ops 就是授权清单。
#   归属硬判：migrate 只扫自己会话的前缀。要放宽/收紧只有主人改技能管控表 data/skillctl.json；改本文件无效。
#   拒绝文案带 [权限阻断] 标识（值同 Acl.DENY_PREFIX）。
