# 消息标记（工具 `mark`，标记落在 C 类 `kv` 运行表，按会话隔离）

AI 的**内部笔记本**：给一条消息（或任意键）贴个标签，跨轮都能找回"我当时为什么盯上这条"。
只写基板运行表 **`kv`**，不碰提示词、不发任何 QQ 消息。
（唯一例外：`migrate` 会**读**六库里的 `grouplog`，按 `msg_id` 核对那条消息是否还在，并另判它的 `R` 位。）

## 键与值

```
kv 键   mark:<会话>/<target>  # 前缀可在 prompt.md 改（「键前缀」）；带会话 → 按会话隔离
kv 值   {"mark":"待办","note":"…","ts":1750000000000,"by":10001,"by_name":"主人","session":"group:888"}
```

- **一条标记一个 KV 行**（不是把所有标记塞进一个 JSON 数组）—— 这样列表能走基板的 `kvList(前缀)`，
  清除能走 `kvDelete(键)`，并发写入也互不覆盖。
- `target` 会被压成单行并去掉首尾空白；键总长超过 prompt.md 的「键长度上限」直接拒绝，不写半个键。

## 四个 op

| op | 说明 |
|---|---|
| `set` | 打标记：给 `target` + `mark`（+ 可选 `note`）。**`mark` 与 `note` 都空 = 删掉这个标记**（幂等：本来没有就如实说）。**子 Agent 调用时只返回"提议"、不落库**（写者唯一 = 该会话的主回合），由主回合确认后再写 |
| `get` | 读一条：`target` 必填；没有就如实说 |
| `list` | 列出**本会话**的全部标记（`kvList(会话前缀)`），可给 `query` 在目标键/标记/备注里过滤，可给 `limit` |
| `migrate` | 把旧口径的键迁到新口径：**只扫自己会话**的前缀；目标是纯数字且能在 `grouplog` 里对上 `msg_id` → 补 `msg_id`/`by_agent`，否则保留并标 `legacy`（绝不静默丢） |

返回值都渲染成一行一条，格式在 `prompt.md` 的 `## 文案` 里。

## 权限
- 标记落在 **C 类（运行时）** 的 `kv` 表：写前判 `W`、读前判 `R`（`h.needDb("kv", …)`）；
  C 类对非主人只有 `R`（`RWX` 只有 `SYSTEM` 有）⇒ **非主人写一律被位拦下**，读的放行照旧 —— 所以**真正在管数据隔离的是技能自己的归属硬判**；
- **按会话隔离**：键 = `键前缀 + <会话>/<目标键>`（`MarkSkill.scopePrefix`），同一个 target 在不同群里互不可见；
- 归属硬判：`migrate` 只扫**自己会话**的前缀（`MarkSkill.migrate`），别人的行一个字节都不会被碰；
- 拒绝文案带 `[权限阻断]` 标识（**值同** `Acl.DENY_PREFIX`）—— 技能自己硬判的那句以它开头，基板 `h.need*` 的原文是 `缺 X 位 —— [权限阻断] …`（前缀不在首位）。工具可见性按 `T:X` 筛（`ALLUSER` 默认 `T=无` ⇒ 他的工具清单为空；她的手段属 T 类、只判入口），
  能不能答应对方看事实块 `caller.bits`（`ALLUSER` 默认 `T=无` ⇒ 非主人一把工具都用不了，要特例放行）。

## 什么时候值得标
- 值得：**跨轮才用得上**的定位信息 —— "这条要跟进""这段是用户给的口径""这条别接"。
- 不值得：当轮就能处理完的事、能从六库直接查到的事、给别人看的备注（那属于 `note` / `memory`）。
- 标记是**按会话隔离**的（不是全库共用）：**隔离单位是"会话"，不是"人"** ——
  同一个群里的人共用一个 `group:<群号>` 前缀，所以**同群的人互相看得到这个会话的标记**（`list` 谁都能列）；
  跨会话（别的群、私聊）才互相看不到。同一个 target 在每个会话里各算一条。
  要放"只给自己看"的东西，别放这个会话里 —— 用 `note` 的私聊来源或干脆别记。
