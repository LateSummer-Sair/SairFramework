调用 `forwardmsg` 工具转发消息（仅主人可用）。

## 参数
- message_id: 要转发的消息 ID
- target: 目标 QQ 号/群号/群名/昵称

## 快捷模式
- 引用消息+文本'转发给 XXX'自动识别目标
