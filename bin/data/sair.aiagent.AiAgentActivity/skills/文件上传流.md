NapCat v4.8.115+ 引入的 Stream API，用于大文件传输和跨设备部署。

## 三种 API 类型
- Normal: 普通接口（clean_stream_temp_file 清理临时文件）
- Download: 下载流（download_file_stream 文件 / download_image_stream 图片 / download_record_stream 语音 / test_download_stream 测试）
- Upload: 上传流（upload_file_stream 文件上传）

## upload_file_stream 参数
- stream_id: 流唯一标识（uuid）
- chunk_data: 分块数据（base64 编码）
- chunk_index: 当前块索引（从 0 开始）
- total_chunks: 总块数
- file_size: 文件总字节数

## 响应状态
- type=stream + stream=stream-action: 数据块传输中
- type=response: 流传输成功结束
- type=error: 流传输异常结束
- 普通接口 stream=normal-action

## 注意
- Upload/Download 组 API 的 action name 必须以 stream 结尾
- 传输完成后用 clean_stream_temp_file 清理临时文件
- 适用于 >100MB 大文件、NapCat 与 QQ 客户端跨设备部署
