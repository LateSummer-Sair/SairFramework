调用 `skillextract` 工具触发技能蒸馏，参数 focus 为蒸馏重点（可选）。

## 触发方式
- 显式: 用户说请蒸馏/记住这个方法时自动调用
- 隐式: 每轮 Agent 执行完毕自动分析轨迹

## 工作流程
1. 扫描当前对话的操作轨迹
2. 通过 LLM 分析提取可复用模式
3. 去重后存入 SkillBank 技能库

## 参数
- focus: 可选，指定蒸馏重点

## 示例
- `skillextract` 蒸馏本次任务的模式
- `skillextract` 文件批量处理

## 限制
- 至少需要 2 个有效操作步骤
- 60 秒内不重复触发（显式调用除外）
