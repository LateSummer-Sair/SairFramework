调用 `sendfileto` / `sendfile` 工具发送本地文件给指定联系人。

## 发送链路（文件中转服务）
- 系统内置「文件中转 Web 服务」，把本地文件以 HTTP URL 形式暴露
- 发送文件时，文件先注册到中转服务得到 URL，再作为 file 参数递交 NapCat
- NapCat 下载该 URL 后发送给目标会话
- AI 也可用 `web` 工具抓取中转服务 URL 校验文件内容

## 底层 API
- 群文件: upload_group_file（参数 group_id + file + name，file 支持本地路径或 HTTP URL）
- 私聊文件: upload_private_file（参数 user_id + file + name，file 支持本地路径或 HTTP URL）

## 使用方式
- AI 直接调用 `sendfile`（发当前会话）或 `sendfileto`（发指定联系人）工具即可
- 中转服务由系统自动管理，AI 无需关心端口和 URL 细节

## 限制
- 文件大小有限制，大文件（>100MB）建议走 Stream API（upload_file_stream）
- 群文件会上传到群共享空间，所有群成员可见
- 私聊文件直接发送给目标用户
