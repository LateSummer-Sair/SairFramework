# 技能说明书查询

替代原先 `ToolDispatcher.executeSkillInfo()` 的实现。

- **通道**：三通道都注册；索引里写着「不熟悉某技能/工具用法时先调 skillinfo 查详情」。
- **权限**：`ANY`（只是读文档，不改任何状态）。
- **提供的 FC 工具**：`skillinfo`（沿用原工具名）。

## 使用规则

- 索引里的技能名可以直接查；也可以按「关键词」查（内部会回退到全文检索）。
- 命中后会回写使用计数 —— 这是「哪些经验真被用过」的唯一观测点。
