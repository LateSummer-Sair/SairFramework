# 触发词设置（settrigger）

原硬编码实现：`ToolDispatcher.executeSetTrigger()`。行为一致：非主人直接拒绝；
`list` / 空值 = 查看；否则 `AiConfig.setBotName(words)` + `save()`（内部按 `;` 拆分去重）。

**权限是双层保险**：
1. 技能自身 `permission: MASTER`；
2. 即便有人把这里改成 `permission: ANY`，`HarnessConfig` 的权限矩阵里 `settrigger = MASTER`
   **优先于**技能的声明（V4.0 加的防绕过规则），所以门禁不会被 md 改掉。
