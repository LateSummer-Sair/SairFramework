# 三方技能库管理工具（thirdskill）

原硬编码实现：`ToolDispatcher.executeThirdSkill()`。**这个工具把自己也剥离了** ——
现在连"管理技能库"这件事都是技能文件夹里的源码，改它的措辞或加子命令不用重编译插件。

子命令：`list` / `validate`（重扫+重编译+逐条点名）/ `add 名|描述|内容` / `delete 名`。
底层仍是 `SkillBank.getInstance().getThirdPartyStore()`。

> 注意：本技能只提供 **execs / 本地**通道（与原来一致），execq 普通用户看不到它。
