# 定时任务（schedule）

原硬编码实现：`TagExecutor.executeSchedule()`。调度器从 Java 的 `CronScheduler.getInstance()` 取
（插件启动时登记），**不新建** —— 否则会出现两个调度器各跑一半任务。

子命令与原来一致：`add "cron" "command" ["描述"] | list | remove id | enable id | disable id`。
`cron` 表达式为标准 5 段式（分 时 日 月 周）。
