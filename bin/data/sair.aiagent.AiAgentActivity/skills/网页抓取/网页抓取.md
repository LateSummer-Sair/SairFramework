# 网页抓取（web）

原硬编码实现：`AgentActionHandler.executeWeb()`。三点行为完全保留：

1. **补协议头**：没写 `http(s)://` 时自动补 `https://`。
2. **内网拦截**：`sair.aiagent.util.NetGuard.isInternalHost()` —— 这条检查**故意留在 Java**，
   技能只能调用。理由：技能源码是用户可编辑的文本，安全闸门跟着搬过去就等于"改一行就能打内网"。
3. **确认闸门**：控制台通道下先问「联网获取: xxx，是否允许？」。
4. **成功自动沉淀**：抓取成功后把正文写进知识库（标题前缀 `[网页抓取] `、超 3000 字符截断、异步落库、失败静默）—— 原先挂在 Java 侧的 `autoStoreWebResult` 上，随工具剥离丢失，现已搬回本技能。

底层仍是 `WebFetcher.fetch(url)`（自动跟随重定向、识别编码与 JSON）。
