调用 `alarm` 工具创建系统闹钟，到点后会实实在在唤醒 AI 走 Agent 链路执行任务。

## 子命令
- `alarm` add schedule|task —— 创建闹钟
- `alarm` list —— 列出所有闹钟
- `alarm` remove id —— 移除闹钟（删除快照）
- `alarm` cancel id —— 取消重复闹钟（等价 remove）
- `alarm` append id|备注内容 —— 追加备注到快照（可无限追加直到任务移除）

## schedule 格式（AI 负责把自然语言翻译成此格式）
- once:yyyy-MM-dd HH:mm —— 一次性（到点触发即视为完成，自动移除）
- daily:HH:mm —— 每天固定时刻
- weekly:D,HH:mm —— 每周固定星期几，D=1周一~7周日

## 语义分析规则
- "每天"/"每日" → daily:HH:mm
- "每周一/周二..."/"每星期几" → weekly:D,HH:mm
- "明天"/"下周三"/"某月某日几点" 等一次性 → once:yyyy-MM-dd HH:mm
- 只给相对时间无明确日期时，按最近一次该时刻计算 once 日期

## 权限分级
- execq 普通用户 → REMIND（到点仅发送提醒，不执行任务）
- execq 主人 → EXECQ（到点走受限 Agent 链路执行）
- execs / 本地控制台 → EXECS（到点走全权限 Agent 链路执行）

## 注意
- task 描述要清晰完整，因为到点时 AI 会以快照上下文重新执行它
- 创建闹钟时会自动保存当时的上下文快照，到点按快照重建上下文
