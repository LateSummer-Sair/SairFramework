本系统有两种代码执行方式，本质完全不同，务必区分：

## eval = 动态注入（Java 代码）
- 将 Java 源码编译后加载进 JVM 执行，是真正「注入」一个类
- 能力最强，可调用 SFW 内部 API、反射访问运行时任意对象，是最终兜底手段

## evaljs = 动态执行（JavaScript 脚本）
- 在 Nashorn 引擎中解释执行 JS 脚本，只是「执行」一段脚本，非注入
- 适合快速脚本、HTTP 请求、数据处理，能力弱于 eval

## 铁律
- 兜底必须用 eval（动态注入），绝不能用 evaljs 替代
- 最长执行时间: 30 秒，输出截断: 10000 字符
- execq 通道: `eval` 破例可用于「多对象拆分搜索」场景，其他场景仍禁用；`evaljs` 始终不可用
