# 文件查找（findfile）

原硬编码实现：`AgentActionHandler.executeFindFile()`。行为一致：过确认闸门 → `FileUtils.findFiles(path, keyword)`。

用法建议：先用本工具按关键词定位（比逐层 `readdir` 快得多），再用 `readfile` 读具体文件。
