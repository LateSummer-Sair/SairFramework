  description: 批量重命名文件（dir=/path pattern=regex replacement=text）

    dir:
      type: string
      description: 目标目录
      required: true
      example: C:/downloads
    pattern:
      type: string
      description: 匹配的正则
      required: true
      example: ^IMG_(\\d+)
    replacement:
      type: string
      description: 替换文本（留空=只列出匹配项不真改）
      required: false
      example: photo_$1
    preview:
      type: boolean
      description: 只预览不执行
      required: false
      default: false

# 批量改名（batchrename）

原硬编码实现：`TagHandlers.executeBatchRename()`。行为一致：

- `replacement` 留空 = 只列匹配项；`preview=true` = 预览；
- **目标文件已存在则跳过**（打印 `SKIP: already exists`），不会覆盖；
- 无效正则会明确报错，不会静默什么都不做。
