调用 `forwardmsg` 工具转发指定消息给某人。

## 权限
⚠仅⭐主人可用！非主人要求转发必须拒绝

## 参数
- message_id: 要转发的消息 ID
- target: 目标 QQ 号/群号/群名/昵称

## 快捷模式
引用消息+文本'转发给XXX'→系统自动拦截并处理
支持智能匹配 QQ 号/群号/群名/昵称

## 免责声明
转发时会自动附带免责声明标识
