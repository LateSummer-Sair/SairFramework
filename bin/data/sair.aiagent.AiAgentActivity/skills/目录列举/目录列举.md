# 目录列举（readdir）

原硬编码实现：`AgentActionHandler.executeReadDir()`。行为一致：先过确认闸门 → `FileUtils.readDir(path)`
→ 返回 `目录 [path]:\n<结构>`。

配合 `findfile`（递归按关键词找）先定位、再 readdir 看结构，是探索目录树的标准两步。
