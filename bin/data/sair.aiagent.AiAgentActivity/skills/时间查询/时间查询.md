# 时间查询

替代原先硬编码在 `ToolDispatcher.executeTime()` 里的实现。

- **通道**：`execq`（QQ 普通消息）/ `execs`（QQ execs: 全权限）/ `console`（SFW 控制台）—— 三通道都注册。
- **权限**：`ANY`——无门槛，任何人在任何通道都可以问时间。
- **提供的 FC 工具**：`time`（**沿用原工具名**，模型侧完全无感；内置实现作为兜底保留，
  本 .md 存在时优先走这里）。

## 规则

- 需要日期/时间时**必须**调用本工具，不要凭记忆猜测（模型没有实时时钟）。
- 返回格式固定为 `当前时间: yyyy-MM-dd HH:mm:ss 星期X`，直接原样使用即可。
