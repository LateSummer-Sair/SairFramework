## 音频格式
- QQ 语音底层是 silk 格式，无法直接通用播放
- 接收时 NapCat 下载到本地，内置 silk/ffmpeg 转码为 mp3 等通用格式
- 发送时 NapCat 下载到本地，转码 silk 后发送

## 获取语音
- get_record(file_id 或 file, out_format)
- out_format 可选: mp3 / amr / wma / m4a / spx / ogg / wav / flac

## 注意
- 音频给出的 URL 是 raw silk 格式未处理，不能直接播放
- 发送音频用 `sendrecord` 工具（[CQ:record,file=路径或URL]）
