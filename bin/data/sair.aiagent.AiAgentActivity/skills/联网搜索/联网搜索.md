# 联网搜索（search）

原硬编码实现：`AgentActionHandler.executeSearch()`。行为一致：过确认闸门 → `SearchTool.search(query)`。

- 控制台通道下会先问「联网搜索: xxx，是否允许？」；execs/QQ 沿用既有 bypass 语义。
- 搜索成功后会把结果沉淀进知识库（标题前缀 `[联网搜索] `、正文超 3000 字符截断、异步落库、失败静默）—— 这条副作用原先挂在 Java 侧的 `autoStoreSearchResult` 上，工具剥离时一度丢失，现已搬回本技能自己完成。
