# 纠错记录（correct）

原硬编码实现：`ToolDispatcher.executeCorrect()`。行为一致：内容为空则拒绝；主题缺省 `general`；
写入 `PersistenceManager.addCorrection(topic, content, viewpoint, "ai", qq)`。

**关键点**：来源 QQ 号来自**只读上下文** `ctx.user_id`（原来是读 `ToolContext.senderQQ`）——
这正是技能能拿到的那部分数据，所以纠错记录可以带用户归属，不需要可写句柄。
