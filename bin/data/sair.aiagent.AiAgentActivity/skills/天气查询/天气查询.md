# 天气查询（weather）

原硬编码实现：`AgentActionHandler.executeWeather()` → `sair.aiagent.util.WeatherTool.queryWeather(city)`。

剥离后行为一致（空城市名也照样交给 WeatherTool 处理，由它决定默认城市）。
`WeatherTool` 本身留在 Java —— 那是**共享工具类**，不跟着具体工具走。

## 用法补充（来自 V3.14 内置工具说明书）

调用 `weather` 工具查询天气，参数 `city` 为城市名（支持中文和英文）。

- 示例：`weather` 北京 / `weather` Tokyo
- 三通道可用（execq / execs / console），权限 `ANY`
