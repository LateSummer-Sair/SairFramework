<eval> 标签允许在运行时生成XML标签，生成的标签会被重新解析执行。

## 用途
- 动态构造多步骤操作流程
- 根据条件生成不同的标签组合
- 实现循环和条件逻辑

## 示例
```
<eval>
for (var i = 0; i < 3; i++) {
    '<web>https://example.com/page' + (i+1) + '</web>\n';
}
</eval>
```

## 限制
- 最长执行时间: 30秒
- 输出结果截断: 10000字符
- execq通道: <eval>不可用
