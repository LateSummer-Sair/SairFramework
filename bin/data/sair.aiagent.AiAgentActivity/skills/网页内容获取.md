本技能仅用于「用户发来 URL/网址时获取该指定页面内容」，不是搜索方式；联网搜索请走「多对象拆分搜索」技能。

调用 `web` 工具获取网页或 API 接口内容，参数 url 为完整地址。

## 参数
- url: 完整的 HTTP/HTTPS 地址

## 特性
- 自动跟随 HTTP 3xx 重定向 + 识别 meta refresh 跳转（最多 5 次）
- 自动识别编码（UTF-8/GBK，乱码自动纠正）
- 自动解压 gzip/deflate 响应
- 自动提取正文（剔除脚本/样式/标签，纯文本返回）
- 自动识别 JSON 接口响应并原样返回结构化数据
- 网络异常自动重试 2 次
- 超时: 连接 10 秒, 读取 20 秒

## 安全
- 内网地址自动拒绝（SSRF 防护）
- 返回内容截断至合理长度

## 局限
- 无法执行 JS：纯前端渲染的动态网页（SPA）抓不到正文，此时应找 API 接口，或用 eval（动态注入）写代码请求
- 需要登录/cookie 的页面无法访问

## 示例
- `web` https://api.example.com/data
- `web` https://zh.wikipedia.org/wiki/Java
