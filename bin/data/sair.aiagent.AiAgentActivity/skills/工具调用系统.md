本系统通过 Function Calling 机制调用工具，你无需输出任何 XML 标签。

完整的工具清单与参数说明以每次请求自动注入的「工具列表」为准，不熟悉的工具先用 skillinfo 工具查询其完整说明书。

## 工具权限
- 本地通道（execs）: execq 工具不可用
- QQ execq 通道: 仅白名单工具可用
