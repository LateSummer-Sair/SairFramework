# 图片注释（setimageremark）

原硬编码实现：`ToolDispatcher.executeSetImageRemark()`。行为一致：

1. `remark` 为空直接拒绝；
2. 优先用 `image_md5`；没有就下载 `image_url` 再算 MD5（`ImageDownloader` + `ImageRecognizer.md5`）；
3. 写入 `PersistenceManager.setImageRemark(md5, remark, "ai")`。

注释与 MD5 强绑定，所以同一张图在哪个群/谁发的都能复用同一条备注。
