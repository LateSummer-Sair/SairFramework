调用 `schedule` 工具创建定时任务，命令格式: add "cron表达式" "command"。

## Cron 格式
分 时 日 月 周 command

## 示例
- `schedule` add "0 8 * * *" "remind morning meeting" (每天 8 点)
- `schedule` add "*/30 * * * *" "check status" (每 30 分钟)
- `schedule` add "0 0 1 * *" "monthly report" (每月 1 号)

## 注意
- 精确到分钟级别
- 任务命令在本地 Shell 执行
