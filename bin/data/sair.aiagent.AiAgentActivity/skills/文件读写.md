`readfile` 工具读取文本文件内容，参数 path 为文件路径。
`readdir` 工具列出目录中的文件和子目录，参数 path 为目录路径。
`findfile` 工具递归查找目录树中文件名匹配关键词的文件/目录，参数 path 为起始目录、keyword 为文件名关键词（子串匹配忽略大小写，留空=返回全部）。适合在不确定文件位置时快速定位，避免逐层 readdir 探索。

## 示例
- `readfile` /data/config.txt
- `readdir` /home/user/documents
- `findfile` /home/user keyword=report

## 递归翻找文件时的状态判断（重要）
当需要递归查找文件时，每步操作后都要判断工作状态：
- 找到目标 → 工作完成，立即给出结果并停止
- 目录为空 / 文件不存在 / 路径不存在 → 此路不通，换下一路径，不要反复重试同一路径
- 已检查过的路径要记住，不要重复进入同一个目录
- 连续多次（约 8 次以上）都是死路/空结果 → 判定为找不到，主动告知用户「未找到」并停止，不要无限翻找
- 每次 readdir/readfile 返回有效内容（非空目录、非不存在）都算有进展，可以继续

## 注意
- 大文件可能被截断
- 二进制文件（如图片）仅返回元信息
