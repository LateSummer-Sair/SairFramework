# 系统提示词（editprompt）

原硬编码实现：`AgentActionHandler.executeEditPrompt()`。行为一致：空内容拒绝、短于 30 字符拒绝、
`AiConfig.getInstance().setSystemPrompt(prompt)`（内部把 systemPrompt.md 写盘）。

剥离后调的是同一个 `AiConfig` 单例，因此写盘位置与热生效语义完全不变。
