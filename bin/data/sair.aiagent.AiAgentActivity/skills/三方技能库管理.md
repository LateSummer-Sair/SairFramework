三方技能库是独立于内置技能库的物理隔离技能仓库，位于 data/skills/ 目录。

## 两种形态
- **纯文档技能**：`data/skills/<技能名>.md`（平铺在根目录，只有文档、没有代码，不注册为 FC 工具）
- **工具技能**：`data/skills/<技能名>/` 文件夹里同时放
  - `<技能名>.md`：front matter 元数据 + 自然语言说明
  - `*.java`：Java 源码（可以有多个文件，辅助类放同目录即可一起编译）
  - 文件夹名、md 文件名、front matter 的 `name` 三者必须完全一致，否则拒绝加载

## 核心规则
- 三方技能库与内置技能库完全隔离，同名技能三方优先覆盖内置
- 所有通道（本地 / execq / QQ execs）都可用三方技能
- 只有 execs 和 QQ execs 能调用 `thirdskill` 工具管理三方库
- 代码只支持 Java；`<java start>…<java end>` 式内嵌代码段自 V4.0 起已废弃（加载期红字提示迁移）

## 子命令
- `thirdskill` list: 列出当前所有三方技能
- `thirdskill` validate: 重扫目录 + 重新编译，逐条点名问题（配对失败 / 编译失败 / 没有 airun / 未声明通道权限）
- `thirdskill` add 技能名|描述|内容: 新增一个纯文档技能（写为 .md 文件并热加载）
- `thirdskill` delete 技能名: 删除一个三方技能（删除对应 .md 文件）

## 修改技能（无 edit 子命令）
- 不提供「改」操作。需要修改技能时，直接编辑 data/skills/ 下的文件即可
- 系统监听 skills 目录及其中的技能文件夹：新增自动加载、删除自动移除、md 或 .java 变更自动重载

## 导入三方技能的方式（无需工具）
- 纯文档：把 .md 放进 data/skills/ 即可
- 带代码：建一个与技能同名的文件夹，把 md 和 .java 都放进去

## 示例
- `thirdskill` list
- `thirdskill` validate
- `thirdskill` add 代码审查|审查代码质量|审查用户提供的代码，指出潜在缺陷和改进建议
- `thirdskill` delete 代码审查

## 安全约束
- 技能名不能包含路径分隔符、两个点、冒号、星号、问号、尖括号、竖线等特殊字符
- 单个文件上限 64KB
- 技能文件夹里只编译 `.java`；`.class`/`.jar` 等二进制绝不会被加载（技能目录不是 classpath）
- 三方技能数量越多，注入上下文的 token 消耗越大，会相应影响 API 余额
- 删除操作会直接删除对应文件/文件夹，不可恢复

## 代码约定（Java）
- 入口方法固定命名为 `airun`，类里必须有它，否则不会注册为 FC 工具
- 同一个技能有多个类都写了 `airun` 时，用 front matter 的 `entry: <类名>` 指定入口类
- 框架把该技能的全部 .java 一起编译（辅助类、内部类都能用），编译产物只存在于内存中
- 可选签名（按此顺序尝试）：airun(Map 入参, Map 上下文) → airun(Map, String) → airun(String, Map)
  → airun(String, String) → airun(Map) → airun(String) → airun()
- 返回 Map/List/数组会自动序列化为 JSON；返回空视为「执行成功但无输出」
- 技能里的 println/print 会被捕获并回显在工具结果里
- 编译/运行 classpath 含 ai.jar 本身，所以能直接调 `PersistenceManager`、`SkillBank` 等插件类
- 拿不到可写句柄（napcatApi/unifiedMemory 等）；需要上下文请声明 `context: true`，
  框架会把只读投影（channel/user_id/group_id/is_master/affection/data_dir…）作为第二个参数传入

## airun 函数签名（推荐声明，让 AI 高效调用）
- 在 front matter 声明 airun 的描述与参数，系统会动态注册成具名工具 tp_技能名（或 tool: 顶替内置工具名）
- 声明格式：
  airun:
    description: 计算数学表达式并返回结果
    params:
      expression:
        type: string
        description: 数学表达式
        required: true
- 参数还支持 default（模型没填时代填）/ enum（限定取值）/ example（示例）/ 数组的 items + items_description
- 可选元数据：returns（返回什么，写进工具描述）/ context（注入只读上下文）/ timeout（秒，5~300）/
  state（per_call 默认每次新实例、shared 复用实例）/ tool（顶替同名内置工具）
- 未声明 airun 参数时，工具退化为单个 args（JSON 字符串）参数，建议补全签名提升准确率
- 调用方式：直接调用 tp_技能名（推荐）；或 callskill 工具（skill=技能名, args=JSON）兜底
- 权限：tp_ 工具默认 AFFECTION:300（主人不受限）；用户可通过 ai/setthirdpartycode off 收紧为仅 execs/本地
