# 知识笔记（note）

原硬编码实现：`TagExecutor.executeNote()`。整段子命令逻辑（add/search/list/get/delete/update）
逐字搬到本技能，仍走 `PersistenceManager` 的同一批 API：

- `search` / `get` 会**回写"被查阅"计数**（`recordNoteHit`）——自动注入不算，显式检索才算；
- 新增走 `addNote`（内部已带两级去重：完全重复直接返回旧编号、近似重复标记合并）；
- 与「笔记去重」`ai/dedup notes` 共用同一套数据，不会各自为政。

> 这个技能与 `快速笔记搜索`（工具名 `searchnote`）是同一份存储的两个入口：
> 本技能是全功能命令行，那个是"给模型一个干净的检索工具"。
