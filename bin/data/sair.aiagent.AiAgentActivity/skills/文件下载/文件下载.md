# 文件下载（download）

原硬编码实现：`AgentActionHandler.executeDownload()`（121 行）。这段是"真逻辑"里最大的一块，剥离后：

| 行为 | 说明 |
|---|---|
| 协议校验 | 非 `http(s)://` 直接拒绝 |
| **内网拦截** | 每一跳都调 Java 的 `NetGuard.isInternalHost()`（**判定留 Java**，技能不能改） |
| 重定向 | 手动跟随，最多 5 跳（每跳都重新做内网检查，防止用 302 绕到内网） |
| 落盘位置 | `ctx.data_dir/downloads/`（技能从只读上下文拿数据目录，不再依赖插件实例） |
| 重名 | 自动加 `_1`…`_99` 后缀，不覆盖已有文件 |
| 体积上限 | 100MB，超限立即中断并删除半截文件 |
| 完成后 | 往记忆里补一条「下载文件: … 来源: … 大小: …」（走 Java 的 `MemoryManager.getInstance()`） |
| 确认闸门 | 控制台下先问「下载文件: xxx，是否允许？」 |

**通道**：`console,execs` —— 与原内置注册一致（execq 普通用户不能下载）。

## 用法补充（来自 V3.14 内置工具说明书）

调用 `download` 工具把网络文件下到本地：

- 文件保存到 `dataDir/downloads/` 目录，重名自动加序号后缀
- 下载记录会写进持久化记忆（来源 + 体积）
- **需要确认**：控制台通道下先问「下载文件: xxx，是否允许？」
- 仅 `console` / `execs` 通道（execq 普通用户不可用）
