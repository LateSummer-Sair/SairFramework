本技能是【唯一】的联网搜索方式，永久替换普通 web 搜索，普通整句搜索已废弃禁用。

所有需要联网搜索/查证的问题（对比、选择、时效信息、热点、多个名词实体等）一律按以下四步法：

## 四步法
1. 拆对象：把问题拆成多个独立对象（人物/物品/概念等名词实体）
2. 判语境：识别问题整体指向的领域/主题（如游戏名、作品名、历史事件等）
3. 逐对象搜索：每个对象单独搜一次，搜索词 = 对象名 + 语境限定词
4. 合并分析：把各对象搜索结果放在一起综合对比，得出结论

## 搜索引擎（重要）
- 【最优先使用必应 Bing】，其次才是其他搜索引擎
- 搜索地址: https://www.bing.com/search?q=搜索词

## 破例允许动态注入（重要！）
本技能【破例允许】使用 eval 动态注入写代码执行搜索：
- 可用 Java 代码（HttpURLConnection 等）并发抓取多个对象的搜索结果并解析合并
- 这是全项目唯一允许主动使用动态注入的场景；其他技能/场景仍只把 eval 当兜底
- 所有通道（本地 execs / QQ execq / QQ execs:）均破例允许用 eval 做多对象拆分搜索

## 示例
用户问：「丝柯克用什么武器好？风鹰剑还是雾切之回光？」
语境 = 原神；拆成 3 个对象分别搜（优先必应）：
- `web` https://www.bing.com/search?q=原神 丝柯克
- `web` https://www.bing.com/search?q=原神 风鹰剑
- `web` https://www.bing.com/search?q=原神 雾切之回光
搜完后综合三者信息分析，给出结论

## 注意
- 搜索词一定要带上语境限定词，避免搜到无关内容
- 只输出最终结论，不要输出拆解和搜索过程
