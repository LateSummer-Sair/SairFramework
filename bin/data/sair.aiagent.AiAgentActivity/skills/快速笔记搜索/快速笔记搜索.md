# 快速笔记搜索

替代原先 `TagExecutor.executeNote("search ...")` 的实现。

- **通道**：`execq` / `execs` / `console` —— 三通道都注册（知识库是本地 SQLite，任何通道都读得到）。
- **权限**：`ANY`。
- **提供的 FC 工具**：`searchnote`（沿用原工具名）。

## 使用规则

- 回答「之前记过吗 / 有没有相关资料」之前**先查笔记**，不要凭空回忆。
- 写入新笔记前也先查重（避免重复存储同一条知识）。
